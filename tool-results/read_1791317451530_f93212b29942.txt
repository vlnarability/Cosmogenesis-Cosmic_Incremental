     1→// Omnipotence — Layer 7 prestige content
     2→//
     3→// When a god reaches Omnipotence it learns to deny natural boundaries. Two
     4→// archetypes fuse into one run via a Hybrid Lineage — power and paradox
     5→// growing in the same hand. The Instability meter rises with each
     6→// contradiction; pick a Stance (Contained / Balanced / Embraced) to decide
     7→// whether to suppress, accept, or feed the chaos. Survive a meter peak
     8→// without overflowing and the god earns the right to choose its Divine Face.
     9→//
    10→// Three mechanic families live in this file:
    11→//
    12→//   1. Hybrid Lineages (8)  — bind two archetypes into one run; each pair
    13→//                             grants an upside (production / caps / pop
    14→//                             growth / military / science mults) at the
    15→//                             cost of an instability-per-second gain.
    16→//   2. Instability Meter    — a 0..100 resource that rises each tick at
    17→//                             the bound hybrid's rate × the active stance's
    18→//                             multiplier. At INSTABILITY_MAX the run ends
    19→//                             (the paradox shatters the god). Until then
    20→//                             the player races to prestige before overflow.
    21→//   3. Stances (3)          — Contained (instability ×0.5, hybrid bonuses
    22→//                             ×0.5), Balanced (×1.0, ×1.0), Embraced
    23→//                             (×1.5, ×2.0). One active per run.
    24→//
    25→// State fields (planned for GameState — to be wired in a follow-up task):
    26→//   - activeHybrid:                 string | null             // bound hybrid lineage id, or null before bind
    27→//   - activeStance:                 string                    // active stance id (defaults to "balanced")
    28→//   - instability:                  number                    // current instability meter (0..100)
    29→//   - peakInstability:              number                    // max instability reached this run
    30→//   - survivedPeaksAllTime:         Record<string, boolean>   // per-stance "peak survived" mastery (persistent)
    31→//   - hybridLineagesBoundAllTime:   Record<string, boolean>   // cumulative hybrids ever bound (persistent)
    32→//
    33→// Reference: Omnipotence is new to the TS port — the vanilla JS had no
    34→// Layer 7+ content. The 8 hybrid pair list, 3 stances, and INSTABILITY_MAX
    35→// / BASE_INSTABILITY_RATE constants come straight from the L7-data task
    36→// spec. The hybrid `archetypes` tuples reference the 13 archetype ids
    37→// defined in `archetypes.ts` (9 basic + 4 rare) — each fusion pairs one
    38→// or two rare archetypes with a basic one for the paradox to bite.
    39→//
    40→// Advancement to Layer 8 (Divinity) requires surviving an Instability
    41→// peak without the meter overflowing — see prestigeLayers.ts
    42→// `omnipotence.completeState: "Survive an Instability peak without the meter overflowing"`.
    43→
    44→// =====================================================================
    45→// Constants
    46→// =====================================================================
    47→
    48→/**
    49→ * Maximum instability value. When `state.instability` reaches this number
    50→ * the run ends — the paradox sustaining the Hybrid Lineage shatters and
    51→ * the god is cast back. The player should manage instability via Stance
    52→ * selection (Contained slows the rise) and time their prestige before
    53→ * overflow. Matches `prestigeLayers.ts omnipotence.completeState` wording
    54→ * "without the meter overflowing".
    55→ */
    56→export const INSTABILITY_MAX: number = 100;
    57→
    58→/**
    59→ * Base instability accumulation rate, in points per second, before the
    60→ * bound hybrid and active stance modify it. Used by `instabilityRateMult`
    61→ * as the fallback when no Hybrid Lineage is bound — the inherent paradox
    62→ * of sustaining Omnipotence at all, even without a fusion to feed it.
    63→ * Effective rate each tick is `instabilityRateMult(state.activeStance, state.activeHybrid)`.
    64→ *
    65→ * At 0.3/s in Balanced stance with no hybrid bound, the meter fills the
    66→ * 0..100 range in 100 / 0.3 ≈ 333 seconds (~5.5 minutes). Contained
    67→ * doubles that to ~11 minutes; Embraced cuts it to ~3.7 minutes. Bound
    68→ * hybrids with higher `instabilityPerSec` fill the meter faster still.
    69→ */
    70→export const BASE_INSTABILITY_RATE: number = 0.3;
    71→
    72→/**
    73→ * Peak threshold for the Layer 7 completion check (`isOmnipotenceComplete`).
    74→ * The peak must reach (or exceed) this value during the run to count as
    75→ * "surviving a peak" — a meter that never came close to overflow doesn't
    76→ * demonstrate the player has weathered a real paradox. Set at 80 to leave
    77→ * a 20-point safety margin below INSTABILITY_MAX. Matches the spec wording
    78→ * "Survive an Instability peak without the meter overflowing".
    79→ *
    80→ * Not exported (internal) — `isOmnipotenceComplete` is the only consumer.
    81→ */
    82→const OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD: number = 80;
    83→
    84→// =====================================================================
    85→// 1. Hybrid Lineages (8) — bind two archetypes into one run
    86→// =====================================================================
    87→
    88→/**
    89→ * A single Hybrid Lineage. Only one hybrid can be bound per run (mirrors
    90→ * the Worship Mode / Relic Loadout pattern from earlier layers —
    91→ * `activeHybrid` in GameState is a single id, not a set). The store
    92→ * applies the bound hybrid's bonuses each tick via
    93→ * `hybridBonus(state.activeHybrid)`, multiplied by the active stance's
    94→ * `hybridMult`.
    95→ *
    96→ * Effect field → consumer wiring:
    97→ *   - `productionMult`         → additive all-production mult
    98→ *   - `populationGrowthMult`   → additive pop-growth mult
    99→ *   - `scienceMult`            → additive science mult
   100→ *   - `militaryMult`           → additive military mult
   101→ *   - `capsMult`               → additive multiplier on every resource cap
   102→ *   - `instabilityPerSec`     → the rate (points/sec) at which the
   103→ *                                Instability meter rises while this
   104→ *                                hybrid is bound, BEFORE the stance
   105→ *                                modifier (see `instabilityRateMult`)
   106→ *
   107→ * `instabilityPerSec` is a cost, not a bonus — but it lives on the
   108→ * hybrid (not the stance) because each fusion's paradox strength is
   109→ * unique to the archetype pair. The stance modifier multiplies it; see
   110→ * `instabilityRateMult(stanceId, hybridId)`.
   111→ *
   112→ * `archetypes` is informational (a 2-tuple of archetype ids from
   113→ * `archetypes.ts`) — used by the UI to show the fusion. Not enforced by
   114→ * the validator beyond "exactly two distinct entries".
   115→ */
   116→export interface HybridLineageDef {
   117→  /** Stable identifier (used as a key in `activeHybrid` / `hybridLineagesBoundAllTime`). */
   118→  id: string;
   119→  /** Human-readable hybrid lineage name. */
   120→  name: string;
   121→  /** Narrative / mechanical flavour describing what the fusion creates. */
   122→  desc: string;
   123→  /** Emoji glyph shown on the hybrid card. */
   124→  icon: string;
   125→  /** The two archetype ids (lowercase, matching `archetypes.ts`) being fused. Order is informational. */
   126→  archetypes: [string, string];
   127→  /** Additive all-production multiplier (0.15 = +15% all production). */
   128→  productionMult?: number;
   129→  /** Additive population-growth multiplier (0.25 = +25% pop growth). */
   130→  populationGrowthMult?: number;
   131→  /** Additive science multiplier (0.30 = +30% science). */
   132→  scienceMult?: number;
   133→  /** Additive military-power multiplier (0.20 = +20% military). */
   134→  militaryMult?: number;
   135→  /** Additive multiplier on every resource's cap (0.20 = +20% caps). */
   136→  capsMult?: number;
   137→  /** Instability gain per second while bound, before the stance modifier (0.30 = +0.3/s). */
   138→  instabilityPerSec: number;
   139→}

   246→// =====================================================================
   247→// 2. Stances (3) — how to handle instability
   248→// =====================================================================
   249→
   250→/**
   251→ * A single Stance. Only one stance can be active per run (mirrors the
   252→ * Worship Mode / Relic Loadout / Hybrid Lineage "pick one" pattern). The
   253→ * store reads `stance.instabilityMult` and `stance.hybridMult` each tick
   254→ * via `STANCE_MAP[state.activeStance]`.
   255→ *
   256→ * Stance field → consumer wiring:
   257→ *   - `instabilityMult`  → multiplier on the bound hybrid's `instabilityPerSec`
   258→ *                          (or `BASE_INSTABILITY_RATE` if no hybrid is bound).
   259→ *                          Contained ×0.5, Balanced ×1.0, Embraced ×1.5.
   260→ *   - `hybridMult`       → multiplier on every bonus field returned by
   261→ *                          `hybridBonus(activeHybrid)`. Contained ×0.5
   262→ *                          (bonuses halved), Balanced ×1.0, Embraced ×2.0
   263→ *                          (bonuses doubled).
   264→ *
   265→ * The two multipliers are intentionally coupled: Contained trades half
   266→ * the hybrid's power for half the instability cost; Embraced doubles
   267→ * the power at 1.5× the cost. Balanced is the no-trade baseline. The
   268→ * asymmetry (Contained's cost/power ratio is 1:1, Embraced's is 0.75:1)
   269→ * makes Embraced the higher-stakes, higher-reward pick — appropriate for
   270→ * a layer whose completion condition is "survive a peak".
   271→ */
   272→export interface StanceDef {
   273→  /** Stable identifier (used as `activeStance` in GameState). */
   274→  id: string;
   275→  /** Human-readable stance name. */
   276→  name: string;
   277→  /** Narrative / mechanical flavour describing the stance's trade-off. */
   278→  desc: string;
   279→  /** Emoji glyph shown on the stance card. */
   280→  icon: string;
   281→  /** Multiplier on the hybrid's instability-per-sec rate (0.5 = rises 50% slower). */
   282→  instabilityMult: number;
   283→  /** Multiplier on every bonus field from `hybridBonus` (0.5 = bonuses halved). */
   284→  hybridMult: number;
   285→}

   326→// =====================================================================
   327→// Module-load sanity checks
   328→// =====================================================================
   329→
   330→/**
   331→ * Validate the omnipotence data at module load:
   332→ *   - INSTABILITY_MAX > 0 (must allow some meter rise).
   333→ *   - BASE_INSTABILITY_RATE > 0 (must rise when no hybrid is bound).
   334→ *   - OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD is in (0, INSTABILITY_MAX).
   335→ *   - All hybrid lineage ids are unique.
   336→ *   - Each hybrid's `archetypes` tuple has exactly two distinct entries.
   337→ *   - Each hybrid sets at least one bonus field (the upside half of the
   338→ *     fusion; `instabilityPerSec` alone is a cost, not a fusion).
   339→ *   - Each hybrid's `instabilityPerSec` is > 0 (no "free" fusion).
   340→ *   - All mult fields (if set) on hybrids are > 0 (bonuses, never penalties).
   341→ *   - Exactly 3 stances present.
   342→ *   - All stance ids are unique.
   343→ *   - Each stance's `instabilityMult` and `hybridMult` are > 0.
   344→ *   - The "contained" stance slows instability and weakens bonuses (<1, <1).
   345→ *   - The "balanced" stance is the no-trade baseline (==1, ==1).
   346→ *   - The "embraced" stance accelerates instability and amplifies bonuses (>1, >1).
   347→ *
   348→ * Throws on any violation (programmer error, not a runtime / save data
   349→ * error). The check is O(N) and runs once at module import, so it's a
   350→ * no-op on the hot path. Matches the pattern established by `apotheosis.ts`,
   351→ * `singularity.ts`, `transcendence.ts`, and `genesis.ts`.
   352→ */
   353→(function validateOmnipotenceData(): void {
   354→  if (INSTABILITY_MAX <= 0) {
   355→    throw new Error(
   356→      `omnipotence.ts: INSTABILITY_MAX must be > 0 (got ${INSTABILITY_MAX})`
   357→    );
   358→  }
   359→  if (BASE_INSTABILITY_RATE <= 0) {
   360→    throw new Error(
   361→      `omnipotence.ts: BASE_INSTABILITY_RATE must be > 0 (got ${BASE_INSTABILITY_RATE})`
   362→    );
   363→  }
   364→  if (
   365→    OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD <= 0 ||
   366→    OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD >= INSTABILITY_MAX
   367→  ) {
   368→    throw new Error(
   369→      `omnipotence.ts: OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD must be in (0, ${INSTABILITY_MAX}) (got ${OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD})`
   370→    );
   371→  }
   372→
   373→  // ---- Hybrid lineages ----
   374→  const seenHybrid = new Set<string>();
   375→  for (const h of HYBRID_LINEAGES) {
   376→    if (seenHybrid.has(h.id)) {
   377→      throw new Error(`omnipotence.ts: duplicate hybrid lineage id "${h.id}"`);
   378→    }
   379→    seenHybrid.add(h.id);
   380→
   381→    if (h.archetypes.length !== 2) {
   382→      throw new Error(
   383→        `omnipotence.ts: hybrid "${h.id}" archetypes must have exactly 2 entries (got ${h.archetypes.length})`
   384→      );
   385→    }
   386→    if (h.archetypes[0] === h.archetypes[1]) {
   387→      throw new Error(
   388→        `omnipotence.ts: hybrid "${h.id}" archetypes must be distinct (got [${h.archetypes.join(", ")}])`
   389→      );
   390→    }
   391→
   392→    const bonusCount = [
   393→      h.productionMult,
   394→      h.populationGrowthMult,
   395→      h.scienceMult,
   396→      h.militaryMult,
   397→      h.capsMult,
   398→    ].filter((v) => v !== undefined).length;
   399→
   400→    if (bonusCount < 1) {
   401→      throw new Error(
   402→        `omnipotence.ts: hybrid "${h.id}" must set at least one bonus field (set ${bonusCount})`
   403→      );
   404→    }
   405→
   406→    if (h.instabilityPerSec <= 0) {
   407→      throw new Error(
   408→        `omnipotence.ts: hybrid "${h.id}" instabilityPerSec must be > 0 (got ${h.instabilityPerSec})`
   409→      );
   410→    }
   411→
   412→    if (h.productionMult !== undefined && h.productionMult <= 0) {
   413→      throw new Error(
   414→        `omnipotence.ts: hybrid "${h.id}" productionMult must be > 0 (got ${h.productionMult})`
   415→      );
   416→    }
   417→    if (h.populationGrowthMult !== undefined && h.populationGrowthMult <= 0) {
   418→      throw new Error(
   419→        `omnipotence.ts: hybrid "${h.id}" populationGrowthMult must be > 0 (got ${h.populationGrowthMult})`
   420→      );
   421→    }
   422→    if (h.scienceMult !== undefined && h.scienceMult <= 0) {
   423→      throw new Error(
   424→        `omnipotence.ts: hybrid "${h.id}" scienceMult must be > 0 (got ${h.scienceMult})`
   425→      );
   426→    }
   427→    if (h.militaryMult !== undefined && h.militaryMult <= 0) {
   428→      throw new Error(
   429→        `omnipotence.ts: hybrid "${h.id}" militaryMult must be > 0 (got ${h.militaryMult})`
   430→      );
   431→    }
   432→    if (h.capsMult !== undefined && h.capsMult <= 0) {
   433→      throw new Error(
   434→        `omnipotence.ts: hybrid "${h.id}" capsMult must be > 0 (got ${h.capsMult})`
   435→      );
   436→    }
   437→  }
   438→
   439→  // ---- Stances ----
   440→  if (STANCE_COUNT !== 3) {
   441→    throw new Error(
   442→      `omnipotence.ts: expected exactly 3 stances (got ${STANCE_COUNT})`
   443→    );
   444→  }
   445→  const seenStance = new Set<string>();
   446→  for (const s of STANCES) {
   447→    if (seenStance.has(s.id)) {
   448→      throw new Error(`omnipotence.ts: duplicate stance id "${s.id}"`);
   449→    }
   450→    seenStance.add(s.id);
   451→
   452→    if (s.instabilityMult <= 0) {
   453→      throw new Error(
   454→        `omnipotence.ts: stance "${s.id}" instabilityMult must be > 0 (got ${s.instabilityMult})`
   455→      );
   456→    }
   457→    if (s.hybridMult <= 0) {
   458→      throw new Error(
   459→        `omnipotence.ts: stance "${s.id}" hybridMult must be > 0 (got ${s.hybridMult})`
   460→      );
   461→    }
   462→  }
   463→
   464→  // Verify the three stance ids are present with the spec's trade-offs.
   465→  const contained = STANCE_MAP["contained"];
   466→  const balanced = STANCE_MAP["balanced"];
   467→  const embraced = STANCE_MAP["embraced"];
   468→  if (!contained || !balanced || !embraced) {
   469→    throw new Error(
   470→      `omnipotence.ts: stances must include "contained", "balanced", and "embraced" (got [${STANCES.map((s) => s.id).join(", ")}])`
   471→    );
   472→  }
   473→  if (!(contained.instabilityMult < 1 && contained.hybridMult < 1)) {
   474→    throw new Error(
   475→      `omnipotence.ts: "contained" stance must slow instability (<1) and halve bonuses (<1) — got instabilityMult=${contained.instabilityMult}, hybridMult=${contained.hybridMult}`
   476→    );
   477→  }
   478→  if (balanced.instabilityMult !== 1 || balanced.hybridMult !== 1) {
   479→    throw new Error(
   480→      `omnipotence.ts: "balanced" stance must be the no-trade baseline (1.0, 1.0) — got instabilityMult=${balanced.instabilityMult}, hybridMult=${balanced.hybridMult}`
   481→    );
   482→  }
   483→  if (!(embraced.instabilityMult > 1 && embraced.hybridMult > 1)) {
   484→    throw new Error(
   485→      `omnipotence.ts: "embraced" stance must accelerate instability (>1) and amplify bonuses (>1) — got instabilityMult=${embraced.instabilityMult}, hybridMult=${embraced.hybridMult}`
   486→    );
   487→  }
   488→})();
   489→
   490→// =====================================================================
   491→// Helpers
   492→// =====================================================================
   493→
   494→/**
   495→ * Aggregated bonus object returned by `hybridBonus`.
   496→ *
   497→ * All mult fields are additive on top of the baseline (0 = no change).
   498→ * `instabilityPerSec` is the RAW per-second instability gain from the
   499→ * bound hybrid (BEFORE the stance modifier — the consumer composes the
   500→ * stance modifier via `instabilityRateMult`). The consumer applies the
   501→ * mult fields in the tick loop:
   502→ *
   503→ *   - `productionMult`:        multiply production by `(1 + productionMult × stance.hybridMult)`
   504→ *   - `populationGrowthMult`:  multiply pop growth by `(1 + populationGrowthMult × stance.hybridMult)`
   505→ *   - `scienceMult`:           multiply science by `(1 + scienceMult × stance.hybridMult)`
   506→ *   - `militaryMult`:          multiply military by `(1 + militaryMult × stance.hybridMult)`
   507→ *   - `capsMult`:              multiply every resource cap by `(1 + capsMult × stance.hybridMult)`
   508→ *   - `instabilityPerSec`:     compose with stance via `instabilityRateMult`, then add to `state.instability`
   509→ *
   510→ * Only one hybrid can be bound per run (`state.activeHybrid` is a single
   511→ * id, not a set), so the aggregate is just the bound hybrid's fields
   512→ * passed through with defaults. The consumer multiplies the bonus fields
   513→ * by `stance.hybridMult` (Contained ×0.5, Balanced ×1.0, Embraced ×2.0)
   514→ * at the call site — that coupling is what makes a Stance more than a
   515→ * label. `instabilityPerSec` is returned raw (NOT pre-multiplied) so the
   516→ * consumer can compose it with `stance.instabilityMult` via
   517→ * `instabilityRateMult(stanceId, hybridId)` for the actual rate.
   518→ */
   519→export interface HybridBonus {
   520→  /** Additive all-production multiplier (Photosynthetic Crystal +0.15, Plague Bearer +0.15, etc.). */
   521→  productionMult: number;
   522→  /** Additive population-growth multiplier (Warm-Blooded Hunter +0.25, Venomous Warmth +0.30). */
   523→  populationGrowthMult: number;
   524→  /** Additive science multiplier (Plague Bearer +0.30, Bloom of Death +0.20). */
   525→  scienceMult: number;
   526→  /** Additive military-power multiplier (Warm-Blooded Hunter +0.20, Venomous Warmth +0.15). */
   527→  militaryMult: number;
   528→  /** Additive multiplier on every resource's cap (Photosynthetic Crystal +0.20, Crystal Survivor +0.30). */
   529→  capsMult: number;
   530→  /** Raw per-second instability gain (BEFORE stance modifier). Adaptive Genesis +0.25, Plague Bearer +0.50. */
   531→  instabilityPerSec: number;
   532→}
   533→
   534→/**
   535→ * Return the bound hybrid lineage's bonuses as a single aggregate object.
   536→ *
   537→ * Only one hybrid can be bound per run (`state.activeHybrid` is a single
   538→ * id, not a set — mirrors the Worship Mode / Relic Loadout pattern from
   539→ * earlier layers). The aggregate is just the bound hybrid's stat fields
   540→ * passed through with defaults (0 for all fields). The consumer
   541→ * multiplies the bonus fields by the active stance's `hybridMult`
   542→ * (Contained ×0.5, Balanced ×1.0, Embraced ×2.0) at the call site.
   543→ *
   544→ * Used by the tick loop to compute per-resource multipliers, the pop-
   545→ * growth rate, and cap multipliers. `instabilityPerSec` is returned raw
   546→ * so the consumer can compose it with the stance modifier separately via
   547→ * `instabilityRateMult(stanceId, hybridId)` — that's where the
   548→ * `× stance.instabilityMult` happens.
   549→ *
   550→ * @param hybridId  The bound hybrid lineage id, or `null` if none.
   551→ * @returns Aggregated `HybridBonus` (all fields defaulted for null / unknown input).
   552→ *
   553→ * @example
   554→ *   hybridBonus(null)
   555→ *     // → { productionMult:0, ..., instabilityPerSec:0 }
   556→ *   hybridBonus("photosynthetic_crystal")
   557→ *     // → { productionMult:0.15, capsMult:0.20, instabilityPerSec:0.30, ... }
   558→ *   hybridBonus("plague_bearer")
   559→ *     // → { productionMult:0.15, scienceMult:0.30, instabilityPerSec:0.50, ... }
   560→ *   hybridBonus("adaptive_genesis")
   561→ *     // → { productionMult:0.20, capsMult:0.15, instabilityPerSec:0.25, ... }
   562→ *   hybridBonus("nonexistent_id")
   563→ *     // → { all defaults }  (unknown id treated as "no hybrid")
   564→ */
   565→export function hybridBonus(
   566→  hybridId: string | null
   567→): HybridBonus {
   568→  const result: HybridBonus = {
   569→    productionMult: 0,
   570→    populationGrowthMult: 0,
   571→    scienceMult: 0,
   572→    militaryMult: 0,
   573→    capsMult: 0,
   574→    instabilityPerSec: 0,
   575→  };
   576→  if (!hybridId) return result;
   577→  const hybrid = HYBRID_LINEAGE_MAP[hybridId];
   578→  if (!hybrid) return result;
   579→  if (hybrid.productionMult !== undefined) result.productionMult = hybrid.productionMult;
   580→  if (hybrid.populationGrowthMult !== undefined) result.populationGrowthMult = hybrid.populationGrowthMult;
   581→  if (hybrid.scienceMult !== undefined) result.scienceMult = hybrid.scienceMult;
   582→  if (hybrid.militaryMult !== undefined) result.militaryMult = hybrid.militaryMult;
   583→  if (hybrid.capsMult !== undefined) result.capsMult = hybrid.capsMult;
   584→  if (hybrid.instabilityPerSec !== undefined) result.instabilityPerSec = hybrid.instabilityPerSec;
   585→  return result;
   586→}
   587→
   588→/**
   589→ * Effective per-second instability rate for the given stance + hybrid
   590→ * combination. Composes the bound hybrid's `instabilityPerSec` (or
   591→ * `BASE_INSTABILITY_RATE` if no hybrid is bound) with the active stance's
   592→ * `instabilityMult`:
   593→ *
   594→ *   effectiveRate = (hybrid ? hybrid.instabilityPerSec : BASE_INSTABILITY_RATE) × stance.instabilityMult
   595→ *
   596→ * The consumer adds this value to `state.instability` each tick. When the
   597→ * meter reaches `INSTABILITY_MAX`, the run ends (the paradox shatters).
   598→ *
   599→ * Used by the tick loop in conjunction with `hybridBonus` — the hybrid's
   600→ * bonuses feed production / caps / pop growth / etc., while this function
   601→ * feeds the instability rise. The two are intentionally separate so the
   602→ * consumer can choose to apply one without the other (e.g. suppress the
   603→ * instability rise during a "trial of stasis" event while keeping the
   604→ * hybrid's bonuses active, or apply the stance's bonus multiplier to a
   605→ * hybrid's production while holding the meter steady for a boss fight).
   606→ *
   607→ * @param stanceId  The active stance id, or `null` (treated as "balanced" ×1.0).
   608→ * @param hybridId  The bound hybrid lineage id, or `null` (falls back to BASE_INSTABILITY_RATE).
   609→ * @returns Per-second instability rate (always >= 0; stance × base rate).
   610→ *
   611→ * @example
   612→ *   instabilityRateMult("balanced", "photosynthetic_crystal")
   613→ *     // → 0.30 × 1.0 = 0.30  (Balanced stance, Plantoid×Lithoid hybrid)
   614→ *   instabilityRateMult("contained", "plague_bearer")
   615→ *     // → 0.50 × 0.5 = 0.25  (Contained halves Plague Bearer's paradox)
   616→ *   instabilityRateMult("embraced", "adaptive_genesis")
   617→ *     // → 0.25 × 1.5 = 0.375  (Embraced speeds the safest hybrid)
   618→ *   instabilityRateMult("balanced", null)
   619→ *     // → 0.30 × 1.0 = 0.30  (No hybrid bound: BASE_INSTABILITY_RATE)
   620→ *   instabilityRateMult(null, "plague_bearer")
   621→ *     // → 0.50 × 1.0 = 0.50  (No stance selected: defaults to balanced ×1.0)
   622→ *   instabilityRateMult("nonexistent", null)
   623→ *     // → 0.30 × 1.0 = 0.30  (Unknown stance: defaults to balanced; BASE rate applies)
   624→ */
   625→export function instabilityRateMult(
   626→  stanceId: string | null,
   627→  hybridId: string | null
   628→): number {
   629→  const stance = stanceId ? STANCE_MAP[stanceId] : null;
   630→  const stanceMult = stance ? stance.instabilityMult : 1.0;
   631→  const hybrid = hybridId ? HYBRID_LINEAGE_MAP[hybridId] : null;
   632→  const baseRate = hybrid ? hybrid.instabilityPerSec : BASE_INSTABILITY_RATE;
   633→  return baseRate * stanceMult;
   634→}

   636→/**
   637→ * Whether the Layer 7 (Omnipotence) completion conditions are met.
   638→ *
   639→ * Conditions (both must be true):
   640→ *   1. The instability meter reached a "peak" of at least
   641→ *      `OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD` (80) at some point during
   642→ *      the run — the player weathered a real paradox, not a tame one.
   643→ *   2. The peak never reached `INSTABILITY_MAX` (100) — the meter did not
   644→ *      overflow (an overflow would have ended the run, so reaching this
   645→ *      check at all means the player is still in control).
   646→ *
   647→ * Matches `prestigeLayers.ts omnipotence.completeState: "Survive an
   648→ * Instability peak without the meter overflowing"`. Used by
   649→ * `triggerPrestige()` to gate advancement to Layer 8 (Divinity).
   650→ *
   651→ * The "peak" is the maximum value `state.instability` reached during the
   652→ * run — tracked as `state.peakInstability`, updated each tick via
   653→ * `peakInstability = Math.max(peakInstability, instability)`. This is a
   654→ * per-run field, reset to 0 on prestige.
   655→ *
   656→ * @param peakInstability  Maximum instability value reached this run.
   657→ * @returns `true` if the peak reached the threshold without overflowing.
   658→ *
   659→ * @example
   660→ *   isOmnipotenceComplete(0)
   661→ *     // → false  (no peak weathered yet)
   662→ *   isOmnipotenceComplete(50)
   663→ *     // → false  (peak below threshold — too tame)
   664→ *   isOmnipotenceComplete(79)
   665→ *     // → false  (one short of the threshold)
   666→ *   isOmnipotenceComplete(80)
   667→ *     // → true  (threshold met, did not overflow)
   668→ *   isOmnipotenceComplete(99)
   669→ *     // → true  (peak just under overflow — the closest call)
   670→ *   isOmnipotenceComplete(100)
   671→ *     // → false  (meter overflowed — run would have ended)
   672→ *   isOmnipotenceComplete(120)
   673→ *     // → false  (impossible peak above max — defensive, treated as overflow)
   674→ */
   675→export function isOmnipotenceComplete(
   676→  peakInstability: number
   677→): boolean {
   678→  return (
   679→    peakInstability >= OMNIPOTENCE_COMPLETION_PEAK_THRESHOLD &&
   680→    peakInstability < INSTABILITY_MAX
   681→  );
   682→}
