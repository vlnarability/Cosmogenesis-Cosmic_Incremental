  2462→## Base Game Loop (Cell → Galactic)
  2463→
  2464→### Core Loop Summary
  2465→The base game is a 7-stage linear progression where each stage follows the same 3-requirement gate: reach `minPopulation`, build `minSystems`, research `minTech`, then click Evolve. Inside each stage, the player clicks manual actions to bootstrap resources, buys systems for passive production, researches techs for additive +% bonuses, and waits for population to grow on a continuous curve. There are no branching paths inside a stage — every system/tech can be bought independently and the optimal order is always "cheapest first." The only meaningful fork is the archetype drift system, which locks at Creature→Tribal.
  2466→
  2467→### Fun Assessment
  2468→😐 **OK but flat** — The first playthrough has narrative momentum (great story blurbs per stage, nice visual transitions, archetype drift adds identity), but the actual moment-to-moment gameplay is "buy cheapest thing, wait, repeat." Stage 1-2 have a satisfying bootstrap arc. By stage 3-4 the loop is mechanical. Stages 5-7 are a long idle grind with no new decision points. The dev tacitly admits this: after first Galactic win, all three auto-buyers (systems, techs, evolve) become **FREE**, the game prints "Auto-running — base game progresses on its own," and prestige speed multiplier compounds (`1 + totalRuns * 0.5`). Translation: the base game is explicitly designed to be skipped on replays, which is the design tell that the loop itself isn't intrinsically fun.

  2470→### Stage-by-Stage Feel
  2471→- **Cell** 🪲 **Boring/broken**: Starting pop is 8, evolveRequires.minPopulation is also 8 — the pop requirement is decorative. Cell is essentially "buy 4 systems + 2 techs." ATP gets a free 0.5/s drip making all ATP costs trivial. Manual actions have 0.1-0.4s cooldowns so the player spams clicks for ~2 min then evolves. Story is nice, gameplay is thin.
