   255→  4387→### Allocation system
   256→  4388→- **Available worlds** = `backgroundSimulations` (computed each tick from
   257→  4389→  constellation stars + L4/L5/L6 system claims) − `totalAllocatedWorlds`.
   258→  4390→- `allocateWorlds(portfolioId, count)` — moves worlds from the pool into a
   259→  4391→  portfolio (clamped to available). For Stability Bonds, locks the allocation
   260→  4392→  for `lockDuration` seconds (timer only refreshed when the existing timer is
   261→  4393→  already at 0, so topping up a locked portfolio doesn't extend the lock).
   262→  4394→- `deallocateWorlds(portfolioId, count)` — moves worlds back; **refused** while
   263→  4395→  a Stability Bonds lock timer is active. Logs a "🔒 locked" message.
   264→  4396→- Defensive tick logic: if `backgroundSimulations` shrinks below the total
   265→  4397→  allocated (e.g. player lost galaxies), each allocation is trimmed
   266→  4398→  proportionally so the totals stay valid.

   269→  4401→```
   270→  4402→dividends = allocatedWorlds × portfolio.baseYield × peakProductionRate × 0.01 × realDt
   271→  4403→```

   273→  4405→rule. Dividends are added to `divinity` and tracked separately in

   279→  4411→### Crash mechanics (per portfolio, per tick)
   280→  4412→- Crash roll: `Math.random() < portfolio.crashChance` (only when
   281→  4413→  `peakProductionRate > 0`, so an idle portfolio producing nothing won't crash).
   282→  4414→- On crash: `worldsLost = max(1, floor(alloc × portfolio.crashLoss))`.
   283→  4415→  - Old God Futures: `crashLoss = 1.0` → loses ALL allocated worlds.
   284→  4416→  - Chaos Hedge: loses 30% (rounded down, min 1).
   285→  4417→  - Transcendence Ventures: loses 10% (rounded down, min 1).
   286→  4418→- Crash is logged via `setTimeout(() => get().addToLog(...), 0)` to avoid
   287→  4419→  `setState`-mid-`tick` (the tick uses a single batched `set()` at the end).

   289→  4421→  sacrifice population for a one-time Divinity payout to cover a crash.
