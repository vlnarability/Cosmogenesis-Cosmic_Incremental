     1→     1→// Infinity — Layer 9 prestige content
     2→     2→//
     3→     3→// When a god reaches Infinity it stops being a single civilization and
     4→     4→// becomes a curator of timelines. Completed runs leave behind Echoes that
     5→     5→// provide passive bonuses; Forks split decisions into two branches that
     6→     6→// each define a divergent run-long bonus; Future Debt lets the god borrow
     7→     7→// strength now and pay it back later — at compounding interest.
     8→     8→//
     9→     9→// Three mechanic families live in this file:
    10→    10→//
    11→    11→//   1. Echo Types (6)             — completed runs leave behind echoes that
    12→    12→//                                   provide passive bonuses. Each echo type
    13→    13→//                                   can be owned multiple times; the per-echo
    14→    14→//                                   bonus stacks linearly with the count
    15→    15→//                                   owned. Purchased with the Echoes currency
    16→    16→//                                   earned at Layer 9 prestige.
    17→    17→//   2. Fork Scenarios (4)         — split decisions that create two branches.
    18→    18→//                                   Each fork is resolved once per run by
    19→    19→//                                   picking branch A or B; the chosen branch
    20→    20→//                                   grants a run-long bonus. The Final
    21→    21→//                                   Divergence is the capstone fork: branch
    22→    22→//                                   B's "unlock a random divine law for free"
    23→    23→//                                   is dispatched by the consumer via the
    24→    24→//                                   `special` discriminated union.
    25→    25→//   3. Future Debt Tiers (4)       — borrow strength now, pay back later.
    26→    26→//                                   Each tier grants a production boost for
    27→    27→//                                   `boostDuration` seconds, then applies a
    28→    28→//                                   production penalty for `penaltyDuration`
    29→    29→//                                   seconds. Per-run limit caps how many
    30→    30→//                                   times a tier can be invoked per run.
    31→    31→//
    32→    32→// State fields (planned for GameState — to be wired in a follow-up task):
    33→    33→//   - echoesOwned:                Record<string, number>   // echo id → count owned (persistent across runs)
    34→    34→//   - echoes:                     number                    // current Echoes currency pool
    35→    35→//   - forksResolved:              Record<string, "A" | "B"> // fork id → chosen branch (per-run)
    36→    36→//   - activeFutureDebt:           string | null             // currently active debt tier id, or null
    37→    37→//   - futureDebtPhase:            "boost" | "penalty" | null  // current phase of the active debt
    38→    38→//   - futureDebtTimer:            number                    // seconds remaining in the current phase
    39→    39→//   - futureDebtUses:             Record<string, number>   // times each debt tier invoked this run
    40→    40→//   - futureDebtRepaid:           boolean                   // whether any debt has been fully repaid this run
    41→    41→//
    42→    42→// Reference: Infinity is new to the TS port — the vanilla JS had no
    43→    43→// Layer 9 content. The 6 / 4 / 4 spec, the echo bonus values, the fork
    44→    44→// branch magnitudes, and the future-debt durations come straight from
    45→    45→// the L9-data task spec. The Echoes currency is the Layer 9 prestige
    46→    46→// currency (the same `currency: "Infinity"` field on
    47→    47→// `prestigeLayers.ts infinity`); the Echo Type cost field is denominated
    48→    48→// in that currency.
    49→    49→//
    50→    50→// Advancement to Layer 10 (Eternity) requires forking a timeline AND
    51→    51→// repaying the resulting Future Debt — see prestigeLayers.ts
    52→    52→// `infinity.completeState: "Fork a timeline and repay the resulting
    53→    53→// Future Debt"`. See `isInfinityComplete` for the gating logic.
    54→    54→

    56→    56→// Constants
    57→    57→// =====================================================================

    60→    60→ * Number of Fork Scenarios the player must resolve for the Layer 9

    71→    71→// 1. Echo Types (6) — completed runs leave behind echoes
    72→    72→// =====================================================================
    73→    73→
    74→    74→/**
    75→    75→ * The per-echo bonus fields. Each echo type's `bonus` object can set any
    76→    76→ * subset of these; the consumer applies them additively (each owned copy
    77→    77→ * of the echo contributes its bonus once, summed via `echoBonus`).
    78→    78→ *
    79→    79→ * Effect field → consumer wiring:
    80→    80→ *   - `productionMult`         → additive all-production mult (Trade Echo +0.15)
    81→    81→ *   - `populationGrowthMult`   → additive pop-growth mult (Growth Echo +0.10)
    82→    82→ *   - `militaryMult`           → additive military mult (Conquest Echo +0.15)
    83→    83→ *   - `scienceMult`            → additive science mult (Science Echo +0.15)
    84→    84→ *   - `goldMult`               → additive gold mult (Trade Echo +0.15)
    85→    85→ *   - `capsMult`               → additive mult on every resource cap (Stability Echo +0.10)
    86→    86→ *   - `happinessFlat`          → flat per-tick happiness bonus (Stability Echo +10)
    87→    87→ *   - `divinityPerSec`         → flat per-second Divinity grant (Faith Echo +0.02)
    88→    88→ *
    89→    89→ * All mult fields are additive on top of the baseline (0 = no change).
    90→    90→ * `happinessFlat` is a signed flat per-tick grant (Stability Echo's +10
    91→    91→ * is positive; defaults to 0). `divinityPerSec` is a flat per-second
    92→    92→ * grant added directly to `state.resources.divinity` (Faith Echo's +0.02
    93→    93→ * produces 0.02 Divinity/s per copy owned; 5 copies → 0.1 Divinity/s).
    94→    94→ *
    95→    95→ * The `epMult` field is intentionally absent here — Echoes grant
    96→    96→ * production / growth / military / science / gold / caps / happiness /
    97→    97→ * Divinity, NOT evolution-point multipliers. EP multipliers are
    98→    98→ * exclusive to The Final Divergence fork (see `ForkBranchDef`).
    99→    99→ */
   100→   100→export interface EchoBonusFields {
   101→   101→  /** Additive all-production multiplier (0.15 = +15% all production). */
   102→   102→  productionMult?: number;
   103→   103→  /** Additive population-growth multiplier (0.10 = +10% pop growth). */
   104→   104→  populationGrowthMult?: number;
   105→   105→  /** Additive military-power multiplier (0.15 = +15% military). */
   106→   106→  militaryMult?: number;
   107→   107→  /** Additive science multiplier (0.15 = +15% science). */
   108→   108→  scienceMult?: number;
   109→   109→  /** Additive gold multiplier (0.15 = +15% gold). */
   110→   110→  goldMult?: number;
   111→   111→  /** Additive multiplier on every resource's cap (0.10 = +10% caps). */
   112→   112→  capsMult?: number;
   113→   113→  /** Flat per-tick happiness bonus (signed; +10 = +10 happiness/s). */
   114→   114→  happinessFlat?: number;
   115→   115→  /** Flat Divinity generated per second (+0.02 = +0.02 Divinity/s). */
   116→   116→  divinityPerSec?: number;
   117→   117→}

   119→   119→/**
   120→   120→ * A single Echo Type. Each echo can be owned multiple times — the
   121→   121→ * `echoesOwned` map (persistent across runs, see file header) records
   122→   122→ * the count per echo id. The `bonus` object is applied once per owned
   123→   123→ * copy (5 Growth Echoes → +50% pop growth via `echoBonus`).
   124→   124→ *
   125→   125→ * The `cost` is denominated in the Echoes currency (the Layer 9
   126→   126→ * prestige currency). The wiring task will decide the exact purchase
   127→   127→ * curve — typically each subsequent copy of an echo costs more (e.g.
   128→   128→ * `cost × (1 + count_owned)`), but that scaling is in the store, not

   130→   130→ *
   131→   131→ * Echo Types are intentionally NOT mutually exclusive — the player can
   132→   132→ * own all six simultaneously, and the bonuses stack additively across
   133→   133→ * types (Growth + Science + Conquest + Trade + Stability + Faith is a
   134→   134→ * valid end-game echo loadout). This mirrors the per-channel leveling
   135→   135→ * pattern in `divinity_layer.ts` (all six Prayer Channels can be

   238→   238→// 2. Fork Scenarios (4) — split decisions that create two branches
   239→   239→// =====================================================================
   240→   240→
   241→   241→/**
   242→   242→ * Discriminated union of fork "special interaction" behaviors. Most
   243→   243→ * fork branches grant a flat stat bonus (production / growth / military
   244→   244→ * / science / gold / caps / ep multipliers); a few instead (or also)
   245→   245→ * dispatch a one-time special action handled by the consumer.
   246→   246→ *
   247→   247→ * Known variants:
   248→   248→ *
   249→   249→ *   - `unlock_random_divine_law`   The Final Divergence branch B

   251→   251→ *                                   bypassing its Divinity cost).

   253→   253→export type ForkSpecial =
   254→   254→  /** Unlock a random Divine Law from apotheosis.ts for free (Divinity cost waived).
   255→   255→   *  The consumer picks one codifiable law at random (or from the
   256→   256→   *  player's preferred pool) and codifies it instantly. */
   257→   257→  | { kind: "unlock_random_divine_law" };
   258→   258→
   259→   259→/**
   260→   260→ * A single branch of a fork scenario. Each fork has exactly two
   261→   261→ * branches — `branchA` and `branchB` — and the player picks one per run
   262→   262→ * (the chosen branch's bonus applies for the rest of the run). The
   263→   263→ * `label` is a short identifier shown on the fork card; `desc` is
   264→   264→ * optional narrative flavour.
   265→   265→ *
   266→   266→ * Effect field → consumer wiring:
   267→   267→ *   - `productionMult`         → additive all-production mult
   268→   268→ *   - `populationGrowthMult`   → additive pop-growth mult
   269→   269→ *   - `militaryMult`           → additive military mult
   270→   270→ *   - `scienceMult`             → additive science mult
   271→   271→ *   - `goldMult`                → additive gold mult
   272→   272→ *   - `capsMult`                → additive mult on every resource cap
   273→   273→ *   - `epMult`                  → additive evolution-points multiplier
   274→   274→ *                                 (exclusive to The Final Divergence branch A)
   275→   275→ *   - `special`                 → discriminated union dispatched by the
   276→   276→ *                                 consumer (see `ForkSpecial`)
   277→   277→ *
   278→   278→ * `epMult` is the only field not shared with `EchoBonusFields` — Echoes
   279→   279→ * never boost EP gain; only The Final Divergence fork can. This keeps
   280→   280→ * the EP economy gated behind a single, deliberate late-run decision
   281→   281→ * (matching the spec wording "choose between +100% EP OR unlock a
   282→   282→ * random divine law for free").

   284→   284→ * At least one of the bonus fields or `special` must be set on each
   285→   285→ * branch (enforced by the IIFE validator). Most branches set exactly
   286→   286→ * one bonus field for a clean read; Crossroads of Evolution's branchA
   287→   287→ * and branchB each set one; The Final Divergence's branchB sets ONLY
   288→   288→ * `special` (the unlock action is its entire effect).

   296→   296→  productionMult?: number;

   307→   307→  /** Additive Evolution Points multiplier (1.0 = +100% EP gain). Exclusive to The Final Divergence branch A. */

   429→   429→// 3. Future Debt Tiers (4) — borrow strength now, pay back later
   430→   430→// =====================================================================
   431→   431→
   432→   432→/**
   433→   433→ * A single Future Debt tier. Invoking a debt tier grants a temporary
   434→   434→ * production boost (`boostMult`, additive on production) for
   435→   435→ * `boostDuration` seconds, then immediately applies a production
   436→   436→ * penalty (`penaltyMult`, additive — typically negative) for
   437→   437→ * `penaltyDuration` seconds. The player may invoke a tier up to
   438→   438→ * `perRunLimit` times per run.
   439→   439→ *
   440→   440→ * Effect field → consumer wiring:
   441→   441→ *   - `boostMult`         → during the boost phase, multiply production
   442→   442→ *                            by `(1 + boostMult)` (e.g. +0.50 = ×1.5)
   443→   443→ *   - `boostDuration`     → seconds the boost phase lasts
   444→   444→ *   - `penaltyMult`       → during the penalty phase, multiply
   445→   445→ *                            production by `(1 + penaltyMult)` (e.g.
   446→   446→ *                            -0.25 = ×0.75). Always negative.
   447→   447→ *   - `penaltyDuration`   → seconds the penalty phase lasts
   448→   448→ *   - `perRunLimit`       → max times this tier can be invoked per run
   449→   449→ *
   450→   450→ * The interest curve is intentionally punishing: each tier's penalty
   451→   451→ * duration grows faster than its boost duration, and the penalty
   452→   452→ * multiplier approaches -1.0 (production halted). Critical Debt's
   453→   453→ * -90% for 600s is a near-run-ending penalty — the god pays dearly for
   454→   454→ * the +500% burst. This makes Future Debt a "panic button" rather than
   455→   455→ * a routine accelerator.
   456→   456→ *
   457→   457→ * The completion check (`isInfinityComplete`) requires that at least
   458→   458→ * one debt has been fully repaid — meaning the player has survived a
   459→   459→ * complete boost + penalty cycle without resetting. This proves the
   460→   460→ * god can carry the weight of borrowed power.
   461→   461→ *
   462→   462→ * The tier progression:
   463→   463→ *   - Minor:     +50% for 120s, then -25% for 120s  (1:1 ratio, mild)

   466→   466→ *   - Critical:  +500% for 60s, then -90% for 600s  (1:10 ratio, brutal)
   467→   467→ *
   468→   468→ * Per-run limits are inversely scaled to power: Minor can be invoked
   469→   469→ * 5× per run; Critical only once. This prevents stacking Critical
   470→   470→ * Debt boosts back-to-back to skip the penalty phase entirely.
   471→   471→ */

   792→   792→/**
   793→   793→ * Aggregated bonus object returned by `echoBonus`.
   794→   794→ *
   795→   795→ * All mult fields are additive on top of the baseline (0 = no change).
   796→   796→ * The consumer applies these in the tick loop:
   797→   797→ *
   798→   798→ *   - `productionMult`:        multiply production by `(1 + productionMult)`
   799→   799→ *   - `populationGrowthMult`:  multiply pop growth by `(1 + populationGrowthMult)`
   800→   800→ *   - `militaryMult`:         multiply military by `(1 + militaryMult)`
   801→   801→ *   - `scienceMult`:          multiply science by `(1 + scienceMult)`
   802→   802→ *   - `goldMult`:             multiply gold by `(1 + goldMult)`
   803→   803→ *   - `capsMult`:             multiply every resource cap by `(1 + capsMult)`
   804→   804→ *   - `happinessFlat`:        add to `state.resources.happiness` per tick
   805→   805→ *   - `divinityPerSec`:       add to `state.resources.divinity` per second
   806→   806→ *
   807→   807→ * Each owned echo copy contributes its `bonus` fields once; the
   808→   808→ * aggregate sums them all. With 5 Growth Echoes owned, the aggregate's
   809→   809→ * `populationGrowthMult` is `5 × 0.10 = 0.50` (+50% pop growth).
   810→   810→ *
   811→   811→ * Echoes are persistent across runs (the spec wording "completed runs
   812→   812→ * leave behind echoes that provide passive bonuses" implies they
   813→   813→ * carry forward — the `echoesOwned` map is part of the persistent
   814→   814→ * GameState, not the per-run state). The aggregate is recomputed each
   815→   815→ * tick (it's cheap — 6 entries) so the consumer doesn't need to cache
   816→   816→ * it.
   817→   817→ */
   818→   818→export interface EchoBonus {
   819→   819→  /** Additive all-production multiplier (Trade Echo × count × 0.15). */
   820→   820→  productionMult: number;
   821→   821→  /** Additive population-growth multiplier (Growth Echo × count × 0.10). */
   822→   822→  populationGrowthMult: number;
   823→   823→  /** Additive military-power multiplier (Conquest Echo × count × 0.15). */
   824→   824→  militaryMult: number;
   825→   825→  /** Additive science multiplier (Science Echo × count × 0.15). */
   826→   826→  scienceMult: number;
   827→   827→  /** Additive gold multiplier (Trade Echo × count × 0.15). */
   828→   828→  goldMult: number;
   829→   829→  /** Additive multiplier on every resource's cap (Stability Echo × count × 0.10). */
   830→   830→  capsMult: number;
   831→   831→  /** Flat per-tick happiness bonus (Stability Echo × count × 10). */
   832→   832→  happinessFlat: number;
   833→   833→  /** Flat Divinity generated per second (Faith Echo × count × 0.02). */
   834→   834→  divinityPerSec: number;
   835→   835→}
   836→   836→
   837→   837→/**
   838→   838→ * Sum the bonuses from all owned Echo Types into a single aggregate.
   839→   839→ * Each echo type's `bonus` object is multiplied by the count owned
   840→   840→ * (from the `echoesOwned` map) and added to the corresponding result
   841→   841→ * field.
   842→   842→ *
   843→   843→ * Used by the tick loop to compute per-resource multipliers, the
   844→   844→ * pop-growth rate, the cap multipliers, the per-tick happiness bonus,
   845→   845→ * and the per-second Divinity grant. The aggregate is recomputed each
   846→   846→ * tick (it's cheap — 6 entries) so the consumer doesn't need to cache
   847→   847→ * it.
   848→   848→ *
   849→   849→ * @param echoesOwned  Map of echo id → count owned (0 / absent = none owned).
   850→   850→ * @returns Aggregated `EchoBonus` (all fields defaulted for empty input).
   851→   851→ *
   852→   852→ * @example
   853→   853→ *   echoBonus({})
   854→   854→ *     // → { productionMult:0, ..., happinessFlat:0, divinityPerSec:0 }
   855→   855→ *   echoBonus({ growth_echo: 1 })
   856→   856→ *     // → { populationGrowthMult:0.10, ... }  (1 Growth Echo = +10% pop growth)
   857→   857→ *   echoBonus({ growth_echo: 3 })
   858→   858→ *     // → { populationGrowthMult:0.30, ... }  (3 Growth Echoes = +30% pop growth)
   859→   859→ *   echoBonus({ trade_echo: 2 })
   860→   860→ *     // → { goldMult:0.30, productionMult:0.30, ... }  (2 Trade Echoes = +30% gold AND +30% production)
   861→   861→ *   echoBonus({ stability_echo: 2 })
   862→   862→ *     // → { happinessFlat:20, capsMult:0.20, ... }  (2 Stability Echoes = +20 happiness/s, +20% caps)
   863→   863→ *   echoBonus({ faith_echo: 5 })
   864→   864→ *     // → { divinityPerSec:0.10, ... }  (5 Faith Echoes = +0.10 Divinity/s)

   901→   901→/**
   902→   902→ * Aggregated bonus object returned by `forkBonus`.
   903→   903→ *
   904→   904→ * All mult fields are additive on top of the baseline (0 = no change).
   905→   905→ * `epMult` is additive on the EP-gain multiplier (the consumer
   906→   906→ * multiplies all Evolution Point gains by `(1 + epMult)`; +1.0 means
   907→   907→ * double EP). The `special` field is the chosen branch's special
   908→   908→ * interaction, or `null` if the branch has no special.
   909→   909→ *
   910→   910→ * The consumer applies these in the tick loop:
   911→   911→ *
   912→   912→ *   - `productionMult`:        multiply production by `(1 + productionMult)`
   913→   913→ *   - `populationGrowthMult`:  multiply pop growth by `(1 + populationGrowthMult)`
   914→   914→ *   - `militaryMult`:         multiply military by `(1 + militaryMult)`
   915→   915→ *   - `scienceMult`:          multiply science by `(1 + scienceMult)`
   916→   916→ *   - `goldMult`:             multiply gold by `(1 + goldMult)`
   917→   917→ *   - `capsMult`:             multiply every resource cap by `(1 + capsMult)`
   918→   918→ *   - `epMult`:               multiply EP gains by `(1 + epMult)`
   919→   919→ *   - `special`:               the chosen branch's special interaction, or `null`
   920→   920→ *
   921→   921→ * Specials (e.g. The Final Divergence branch B's
   922→   922→ * `unlock_random_divine_law`) are dispatched separately by the consumer
   923→   923→ * reading `bonus.special.kind` — they're typically one-time actions
   924→   924→ * taken at fork resolution time, not per-tick effects.
   925→   925→ *
   926→   926→ * Only one branch per fork can be resolved per run
   927→   927→ * (`state.forksResolved[forkId]` is a single `"A" | "B"` value, not a
   928→   928→ * set). If the consumer wants the aggregate across ALL resolved forks,
   929→   929→ * they iterate `FORK_SCENARIOS` and call `forkBonus` per fork (see the
   930→   930→ * store wiring task — `forkBonus` is per-fork by design).

   935→   935→  /** Additive population-growth multiplier (Crossroads B +0.50). */
   936→   936→  populationGrowthMult: number;
   937→   937→  /** Additive military-power multiplier (Great Schism A +0.40). */
   938→   938→  militaryMult: number;
   939→   939→  /** Additive science multiplier (Great Schism B +0.40). */
   940→   940→  scienceMult: number;
   941→   941→  /** Additive gold multiplier. */
   942→   942→  goldMult: number;
   943→   943→  /** Additive multiplier on every resource's cap (Realm of Mirrors A +0.30). */
   944→   944→  capsMult: number;
   945→   945→  /** Additive Evolution Points multiplier (Final Divergence A +1.0 = +100% EP). */
   946→   946→  epMult: number;

   948→   948→  special: ForkSpecial | null;

   951→   951→/**
   952→   952→ * Return the chosen branch's bonuses for a single fork scenario.
   953→   953→ *
   954→   954→ * Only one branch per fork can be resolved per run
   955→   955→ * (`state.forksResolved[forkId]` is a single `"A" | "B"` value, not a
   956→   956→ * set). The aggregate is just the chosen branch's stat fields passed
   957→   957→ * through with defaults (0 for mults, `null` for special). The
   958→   958→ * `special` field is returned verbatim so the consumer can dispatch on
   959→   959→ * `special.kind` without a second lookup.
   960→   960→ *
   961→   961→ * Used by the tick loop to compute per-resource multipliers, the
   962→   962→ * pop-growth rate, cap multipliers, and the EP-gain multiplier. Special
   963→   963→ * interactions (The Final Divergence branch B's free Divine Law unlock)
   964→   964→ * are dispatched separately by the consumer reading `bonus.special.kind`.
   965→   965→ *
   966→   966→ * @param forkId   The fork scenario id, or `null` if no fork is being queried.
   967→   967→ * @param branch   The branch key (`"A"` or `"B"`), or `null` if no branch chosen.
   968→   968→ * @returns Aggregated `ForkBonus` (all fields defaulted for null / unknown input).
   969→   969→ *
   970→   970→ * @example
   971→   971→ *   forkBonus(null, null)
   972→   972→ *     // → { productionMult:0, ..., epMult:0, special:null }
   973→   973→ *   forkBonus("crossroads_of_evolution", "A")
   974→   974→ *     // → { productionMult:0.50, ..., epMult:0, special:null }  (+50% production)
   975→   975→ *   forkBonus("crossroads_of_evolution", "B")
   976→   976→ *     // → { populationGrowthMult:0.50, ..., epMult:0, special:null }  (+50% pop growth)
   977→   977→ *   forkBonus("the_great_schism", "A")
   978→   978→ *     // → { militaryMult:0.40, ..., epMult:0, special:null }  (+40% military)
   979→   979→ *   forkBonus("the_great_schism", "B")
   980→   980→ *     // → { scienceMult:0.40, ..., epMult:0, special:null }  (+40% science)
   981→   981→ *   forkBonus("realm_of_mirrors", "A")
   982→   982→ *     // → { capsMult:0.30, ..., epMult:0, special:null }  (+30% caps)
   983→   983→ *   forkBonus("realm_of_mirrors", "B")
   984→   984→ *     // → { productionMult:0.30, ..., epMult:0, special:null }  (+30% all production)
   985→   985→ *   forkBonus("the_final_divergence", "A")
   986→   986→ *     // → { epMult:1.0, ..., special:null }  (+100% EP)
   987→   987→ *   forkBonus("the_final_divergence", "B")
   988→   988→ *     // → { ..., special:{ kind:"unlock_random_divine_law" } }  (free Divine Law)
   989→   989→ *   forkBonus("nonexistent_id", "A")
   990→   990→ *     // → { all defaults, special:null }  (unknown id treated as "no fork")
   991→   991→ *   forkBonus("crossroads_of_evolution", null)
   992→   992→ *     // → { all defaults, special:null }  (no branch chosen yet)
   993→   993→ */
   994→   994→export function forkBonus(
   995→   995→  forkId: string | null,
   996→   996→  branch: "A" | "B" | null
   997→   997→): ForkBonus {

   999→   999→    productionMult: 0,
  1000→  1000→    populationGrowthMult: 0,
  1001→  1001→    militaryMult: 0,
  1002→  1002→    scienceMult: 0,
  1003→  1003→    goldMult: 0,
  1004→  1004→    capsMult: 0,
  1005→  1005→    epMult: 0,
  1006→  1006→    special: null,
  1007→  1007→  };
  1008→  1008→  if (!forkId || !branch) return result;
  1009→  1009→  const fork = FORK_MAP[forkId];
  1010→  1010→  if (!fork) return result;
  1011→  1011→  const branchDef = branch === "A" ? fork.branchA : fork.branchB;
  1012→  1012→  if (branchDef.productionMult !== undefined) result.productionMult = branchDef.productionMult;
  1013→  1013→  if (branchDef.populationGrowthMult !== undefined) result.populationGrowthMult = branchDef.populationGrowthMult;
  1014→  1014→  if (branchDef.militaryMult !== undefined) result.militaryMult = branchDef.militaryMult;
  1015→  1015→  if (branchDef.scienceMult !== undefined) result.scienceMult = branchDef.scienceMult;
  1016→  1016→  if (branchDef.goldMult !== undefined) result.goldMult = branchDef.goldMult;
  1017→  1017→  if (branchDef.capsMult !== undefined) result.capsMult = branchDef.capsMult;
  1018→  1018→  if (branchDef.epMult !== undefined) result.epMult = branchDef.epMult;
  1019→  1019→  if (branchDef.special !== undefined) result.special = branchDef.special;
  1020→  1020→  return result;

  1027→  1027→ *   1. At least `INFINITY_COMPLETION_FORKS_REQUIRED` (1) Fork Scenarios

  1037→  1037→ * boost + penalty cycle on any Future Debt tier — the penalty phase
  1038→  1038→ * ended without the player resetting. This proves the god can carry
  1039→  1039→ * the weight of borrowed power, which is the thematic crux of the
  1040→  1040→ * Infinity layer.
  1041→  1041→ *

  1054→  1054→ *     // → true  (1 fork + debt repaid)
  1055→  1055→ *   isInfinityComplete({
  1056→  1056→ *     crossroads_of_evolution: "A",

  1064→  1064→ *   isInfinityComplete({ crossroads_of_evolution: "A" }, false)

  1072→  1072→    const branch = forksResolved[f.id];
  1073→  1073→    return branch === "A" || branch === "B";
  1074→  1074→  }).length;
  1075→  1075→  return (
  1076→  1076→    resolvedCount >= INFINITY_COMPLETION_FORKS_REQUIRED && debtRepaid
  1077→  1077→  );
  1078→  1078→}
