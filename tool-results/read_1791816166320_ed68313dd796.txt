     5→     5→## Task Summary
     6→     6→Implement the fifth prestige layer (Apotheosis) — the god ceases to be
     7→     7→hidden. Mortals build temples, name the divine, and choose how they will
     8→     8→serve. Four systems:
     9→     9→
    10→    10→1. **Divine Laws** (6) — spend Divinity to enact fundamental rule changes
    11→    11→   that persist for the run. Dark laws (Carnal Pact, Void Pact) are flagged
    12→    12→   with a red border. Laws are permanent for the run — cannot be un-enacted.
    13→    13→2. **Worship Modes** (6) — Devotion / Fear / Duty / Mystery / Transaction /
    14→    14→   Transcendence. Each mode applies persistent multipliers for the run.
    15→    15→   Changing mode costs 3 Divinity (first choice is free).
    16→    16→3. **Miracles** (5) — Bless Harvests, Sanctify Expansion, Declare Jubilee,
    17→    17→   Curse Dissent, Apocalypse Rite (dark). Each costs Divinity AND consumes
    18→    18→   one Miracle Charge. Charges replenish on prestige (2 baseline).
    19→    19→4. **Heresy Management** (4 responses) — competing interpretations arise
    20→    20→   randomly. Respond with Suppress, Absorb, Legalize, or Weaponize. Heresy
    21→    21→   out of control (level reaches 100) ends the run with reduced EP.
    22→    22→
    23→    23→Unlock: Author 2 distinct cradle worlds across runs AND awaken 2 distinct
    24→    24→dormant seeds. Fires the `apotheosis_unlocked` story beat — "Mortals Learn
    25→    25→the Divine Name".

   312→   312→## Design Decisions
   313→   313→
   314→   314→1. **Laws are permanent for the run.** The task spec says "Divine laws
   315→   315→   are permanent for the run (can't un-enact)". `enactLaw()` rejects
   316→   316→   re-enactment via `(s.enactedLaws || []).includes(lawId)` check.
   317→   317→
   318→   318→2. **Worship mode switching costs Divinity.** The task spec says
   319→   319→   "Worship mode can be changed but costs Divinity". I made the first
   320→   320→   choice free (since the player has no mode yet) and each subsequent
   321→   321→   switch costs 3 Divinity. This matches the spec's intent ("changing
   322→   322→   costs Divinity") without making the first mode choice feel punishing.
   323→   323→
   324→   324→3. **Miracles are charge-gated + Divinity-gated.** The task spec says
   325→   325→   "Miracles are limited (charges replenish on prestige)". Each miracle
   326→   326→   requires 1 charge AND its Divinity cost. Charges default to 2 per
   327→   327→   run (baseline). The Apocalypse Rite is the dark miracle — costs 30
   328→   328→   Divinity, takes 30% of population, gives massive resource infusion.
   329→   329→
   330→   330→4. **Heresy is the failure state.** The task spec says "Heresy out of
   331→   331→   control = run ends". I implemented:
   332→   332→   - Random spawn (0.5%/tick chance when conditions are met — roughly
   333→   333→     one heresy event every ~3-4 minutes of active play).
   334→   334→   - Slow level growth (0.5/sec base, accelerating above level 80).
   335→   335→   - Failure at level 100 → `triggerPrestige()` is called with the
   336→   336→     `_heresyEndRun` flag, which halves EP earned.
   337→   337→   - Each response reduces heresy by a different amount (Suppress:
   338→   338→     -25, Absorb: -15, Legalize: -10, Weaponize: -20), with different
   339→   339→     side effects (happiness/military/culture changes).
   340→   340→
   341→   341→5. **The unlock condition uses 2/2 as a proxy** for the design doc's

   343→   343→   There are 8 cradle worlds and 4 dormant seeds; requiring 2/2 means
   344→   344→   the player has experienced Genesis meaningfully (different cradles
   345→   345→   in different runs, plus seen at least 2 seed awakenings). This is
   346→   346→   the same kind of pragmatic proxy Task 24 used for the Genesis

   350→   350→   "trigger prestige with reduced EP". I went with 50% (halved) as a
   351→   351→   meaningful but not catastrophic penalty. The reduction is applied
   352→   352→   multiplicatively with the world EP modifier and stage multiplier,
   353→   353→   so a heresy collapse on an extreme Crystalline world still yields
   354→   354→   more EP than a clean Cell run.

   356→   356→7. **The migration reconstructs `distinctCradlesAuthored` from the
   357→   357→   archive** for legacy saves (pre-Task-25). The archive's `notes`

   359→   359→   I scan the archive for cradle names and add their IDs to the list.

   361→   361→   worlds across runs gets credit toward the Apotheosis unlock on
   362→   362→   first load — they don't have to re-author worlds to "discover"

   368→   368→   `distinctSeedsAwakened` entries will not unlock Apotheosis until

   377→   377→   is 0.15 food/water per pop per second — at 100 pop, that's 15/s,

   437→   437→## Unresolved Issues / Risks
   438→   438→1. **No playtest verification yet.** Reaching the state where Apotheosis
   439→   439→   is unlocked (2 distinct cradle worlds authored across runs AND 2
   440→   440→   distinct seeds awakened) is impractical in the dev environment (would
   441→   441→   require many full Cell→Galactic playthroughs + Genesis world authoring
   442→   442→   + dormant seed awakenings at Tribal/Civ/Empire/Galactic stages). The
   443→   443→   unlock logic, story popup, modal opening, law effects, worship mode
   444→   444→   effects, miracle effects, heresy spawning/growth/response, and heresy
   445→   445→   end-run are all unit-verifiable, but a full playtest is recommended.
   446→   446→
   447→   447→2. **The heresy end-run uses a runtime flag** (`(s as any)._heresyEndRun`)
   448→   448→   rather than a state field. This is intentional — the flag is set by
   449→   449→   the tick() heresy-end-run path right before calling `triggerPrestige()`,
   450→   450→   read inside `triggerPrestige` to halve EP, then cleared. The flag
   451→   451→   doesn't need to persist (it's a transient signal between two methods
   452→   452→   on the same tick). If a save happens mid-tick (rare), the flag would
   453→   453→   be lost — but the next tick would re-evaluate heresy level and
   454→   454→   re-trigger the end-run if needed.
   455→   455→
   456→   456→3. **The heresy spawn chance (0.5%/tick) translates to ~1 event per 3-4
   457→   457→   minutes** of active play. Combined with the 3-minute cooldown after
   458→   458→   spawn AND after a response, this means a player can expect roughly
   459→   459→   one heresy event every 6-8 minutes during Apotheosis runs. This is
   460→   460→   deliberate — frequent enough to create urgency, rare enough not to
   461→   461→   feel like harassment. A playtest should confirm this feels right.
   462→   462→
   463→   463→4. **The "mastered" status for Layer 5** uses the lifetime count of laws
   464→   464→   enacted (across all runs) vs the total divine law count (6). Since
   465→   465→   only one of each law can be enacted per run, this requires the player
   466→   466→   to enact every law at least once across multiple runs — a reasonable
   467→   467→   proxy for "all worship modes and law slots mastered" from the design
   468→   468→   doc. A more strict interpretation would also require trying every
   469→   469→   worship mode, but I didn't want to gate mastery behind an exhaustive
   470→   470→   cross-product (6 laws × 6 modes = 36 combinations).
   471→   471→
   472→   472→5. **Layer 6 (Singularity) is still locked.** Per the design doc,
   473→   473→   Singularity unlocks when the player has "Mastered law, worship,
   474→   474→   miracle, and heresy systems through successful runs." This is a
   475→   475→   complex condition that would require tracking lifetime counts of
   476→   476→   miracles performed, heresies handled, AND laws enacted. Left for a
   477→   477→   future task — the story entry exists in `story.ts`.
   478→   478→
   479→   479→6. **The dark laws (Carnal Pact, Void Pact) don't actually consume
   480→   480→   population** — they generate food/water passively based on current
   481→   481→   population. The "farming people" framing is narrative flavor. A
   482→   482→   stricter interpretation would have population drain over time (the
   483→   483→   people are literally being farmed). I chose the passive-generation
   484→   484→   interpretation because:
   485→   485→   - A pop drain would make the dark laws strictly worse than the
   486→   486→     non-dark alternatives (you'd lose pop AND gain resources).
   487→   487→   - The narrative "farming people" can be read as the population
   488→   488→     being the source of the resource (their labor / their substance
   489→   489→     extracted), not necessarily their deaths.
   490→   490→   - It keeps the dark laws meaningfully different (a unique
   491→   491→     mechanic: pop-based passive production) without being
   492→   492→     mechanically punishing.
   493→   493→   A future task could add a small pop drain (e.g., -1 pop per 100
   494→   494→   food generated) to make the "farming" more literal.
   495→   495→
   496→   496→7. **The `_heresyEndRun` flag pattern is a code smell** — using
   497→   497→   `(state as any)._heresyEndRun` to communicate between tick() and
   498→   498→   triggerPrestige(). A cleaner approach would be to refactor
   499→   499→   triggerPrestige to take an optional `options: { heresyEndRun?: boolean }`
   500→   500→   parameter, but that would change the function signature (which is
   501→   501→   referenced from many places, including `evolveStage` for the Galactic
   502→   502→   endgame). Left as-is for now; documented in the code.
