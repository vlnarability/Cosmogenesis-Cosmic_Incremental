  2276→## Layer 6 — Singularity (Dimension Engine)
  2277→
  2278→### Core Loop
  2279→The player sets time speed (1×/0.5×/0.25×) on three parallel dimensions (Alpha/Beta/Gamma) that passively accrue resources and population, stage up every 100 resources, and eventually reach "Galactic" status. Periodic Rift events every 60s shuffle 25 resources between two dimensions. Player can pay 50 Divinity to sync (copy stage + 50% pop from one dim to another) or collapse (merge two same-stage dims into one with combined speed/pop/resources).   2283→The Dimension Engine is the headline feature of L6 and it is fundamentally a passive progress bar watcher with no reward.   2462→## Base Game Loop (Cell → Galactic)
  2463→
  2464→### Core Loop Summary
  2465→The base game is a 7-stage linear progression where each stage follows the same 3-requirement gate: reach `minPopulation`, build `minSystems`, research `minTech`, then click Evolve. Inside each stage, the player clicks manual actions to bootstrap resources, buys systems for passive production, researches techs for additive +% bonuses, and waits for population to grow on a continuous curve. There are no branching paths inside a stage — every system/tech can be bought independently and the optimal order is always "cheapest first." The only meaningful fork is the archetype drift system, which locks at Creature→Tribal.
  2466→
  2467→### Fun Assessment
  2468→😐 **OK but flat** — The first playthrough has narrative momentum (great story blurbs per stage, nice visual transitions, archetype drift adds identity), but the actual moment-to-moment gameplay is "buy cheapest thing, wait, repeat." Stage 1-2 have a satisfying bootstrap arc. By stage 3-4 the loop is mechanical. Stages 5-7 are a long idle grind with no new decision points. The dev tacitly admits this: after first Galactic win, all three auto-buyers (systems, techs, evolve) become **FREE**, the game prints "Auto-running — base game progresses on its own," and prestige speed multiplier compounds (`1 + totalRuns * 0.5`). Translation: the base game is explicitly designed to be skipped on replays, which is the design tell that the loop itself isn't intrinsically fun.

  2720→## Layer 4 — Genesis (Sacred Grid)
  2721→
  2722→### Core Loop
  2723→
  2724→The player opens the GenesisModal and sees a 5×4 Sacred Grid (20 cells) plus a 5-tile-type picker (Forest/Mountain/Ocean/Desert/Plains).   2760→## Layer 5 — Apotheosis (Heresy Web)
  2761→
  2762→### Core Loop
  2763→
  2764→The player opens the ApotheosisModal and sees an 8×4 Heresy Web (32 follower cells, all starting "faithful"). Every 10 seconds, each heretical cell spreads to one random adjacent faithful cell. Player can Convert a heretic back to faithful for 5 Divinity, or Purge a cell (remove follower entirely, free but -2 Faith). Place up to 2 Prophets (50 Divinity each) on cells — every 10 seconds, each Prophet converts ALL adjacent heretics to faithful. Below the web sit the classic Apotheosis features: 8 Divine Laws (200-1000 Faith each, permanent bonuses, some with heresy tradeoffs), 6 Worship Modes (Faith/sec + production + heresy/sec tradeoffs), 5 Miracles (Faith-cost instant effects), 4 Heresy Responses (policies affecting global heresy rate). Web heresy ≥ 50% triggers a critical alert; global heresy at 100 ends the run. Enact 3+ Divine Laws to unlock Layer 6.

  2768→🪲 Boring or broken
  2769→
  2770→**The Heresy Web is fundamentally broken — heresy never appears in the grid.** `makeInitialFollowerGrid()` (store.ts:220-222) initializes all 32 cells as "faithful". The spread tick (store.ts:1832-1858) only converts faithful cells to heretical IF there's already a heretical cell adjacent — but no code anywhere seeds the first heretic. The player will always see 32/32 faithful, the spread timer ticks but does nothing, Convert/Purge/Prophet actions are useless. Compounding this: the UI hint at ApotheosisModal:70-78 references worship mode IDs (`wm_zeal`, `wm_mystic`, `wm_austere`, `wm_ecstatic`) that DON'T EXIST in `apotheosis.ts` (actual IDs: `wm_silent`, `wm_chanting`, `wm_proselytizing`, `wm_crusade`, `wm_ecstasy`, `wm_void`). The Blessing of the Throne miracle (0 Faith cost, +50 Faith) has no cooldown — infinite Faith exploit. The Heresy Web and Global Heresy meter are disconnected systems with no mechanical link. This layer needs fundamental rework.
