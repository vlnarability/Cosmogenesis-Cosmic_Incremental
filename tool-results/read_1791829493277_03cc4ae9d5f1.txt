  2720→## Layer 4 — Genesis (Sacred Grid)
  2721→
  2722→### Core Loop
  2723→
  2724→The player opens the GenesisModal and sees a 5×4 Sacred Grid (20 cells) plus a 5-tile-type picker (Forest/Mountain/Ocean/Desert/Plains). Click an empty cell with the active tile type to place it. Each tile grants +1% production; each adjacency to a different type grants +0.5%; each group of 3+ matching tiles forms a combo granting +5%. Placing next to empty cells has a 33% chance of revealing a "dormant seed" (visual only — no harvest action). Every 90 seconds there's a 15% chance of a Natural Disaster destroying a random non-mountain tile. Below the grid sits the Author World system: pick 5 components (cradle, prime, geography, dormant seed, difficulty tier), spend 1 Genesis Seed to author a world. Each authored world grants permanent production/cap/EP/pop bonuses. Author 1 world to unlock Layer 5.
  2725→
  2726→### Fun Assessment
  2727→
  2728→😐 OK but flat
  2729→
  2730→The Sacred Grid is a decent mini-game — placing tiles for adjacency bonuses has the bones of a puzzle (like a tiny version of Dorfromantik). But the bonuses are tiny: max grid = +20% (tiles) + ~10% (adjacencies) + ~15% (combos) = ~45% production. Compare to the Author World system right below: each authored world grants +28% to +135% production, and you can author up to 32 worlds per Galactic prestige. The Sacred Grid is dwarfed by Author World — players will minimize time on the grid and maximize authored worlds. The dormant seeds are visual only (REBUILD worklog item 7 flagged this; still unfixed). Disasters feel weak (15% chance every 90s = expected 1 tile lost per 10 min; with 20 cells, this is barely noticeable). The Author World system has 5 sequential pickers with no preview of the resulting world's bonus until after authoring — player has to do mental math.

  2760→## Layer 5 — Apotheosis (Heresy Web)
  2761→
  2762→### Core Loop
  2763→
  2764→The player opens the ApotheosisModal and sees an 8×4 Heresy Web (32 follower cells, all starting "faithful"). Every 10 seconds, each heretical cell spreads to one random adjacent faithful cell. Player can Convert a heretic back to faithful for 5 Divinity, or Purge a cell (remove follower entirely, free but -2 Faith). Place up to 2 Prophets (50 Divinity each) on cells — every 10 seconds, each Prophet converts ALL adjacent heretics to faithful. Below the web sit the classic Apotheosis features: 8 Divine Laws (200-1000 Faith each, permanent bonuses, some with heresy tradeoffs), 6 Worship Modes (Faith/sec + production + heresy/sec tradeoffs), 5 Miracles (Faith-cost instant effects), 4 Heresy Responses (policies affecting global heresy rate). Web heresy ≥ 50% triggers a critical alert; global heresy at 100 ends the run. Enact 3+ Divine Laws to unlock Layer 6.
  2765→
  2766→### Fun Assessment
  2767→
  2768→🪲 Boring or broken
  2769→
  2770→**The Heresy Web is fundamentally broken — heresy never appears in the grid.** `makeInitialFollowerGrid()` (store.ts:220-222) initializes all 32 cells as "faithful". The spread tick (store.ts:1832-1858) only converts faithful cells to heretical IF there's already a heretical cell adjacent — but no code anywhere seeds the first heretic. The player will always see 32/32 faithful, the spread timer ticks but does nothing, Convert/Purge/Prophet actions are useless. Compounding this: the UI hint at ApotheosisModal:70-78 references worship mode IDs (`wm_zeal`, `wm_mystic`, `wm_austere`, `wm_ecstatic`) that DON'T EXIST in `apotheosis.ts` (actual IDs: `wm_silent`, `wm_chanting`, `wm_proselytizing`, `wm_crusade`, `wm_ecstasy`, `wm_void`). So `spreadPattern` always returns "Default" — even if the IDs matched, the spread tick doesn't check worship mode at all. Prophets are useless because there are no heretics. The Blessing of the Throne miracle (0 Faith cost, +50 Faith) has no cooldown — infinite Faith exploit. The Heresy Web and Global Heresy meter are disconnected systems with no mechanical link. This layer needs fundamental rework.
