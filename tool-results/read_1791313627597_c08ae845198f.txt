     1→     1→// Apotheosis — Layer 5 prestige content
     2→     2→//
     3→     3→// When a god reaches Apotheosis, civilization recognizes it. The creator
     4→     4→// is no longer silent: Divine Laws bind the run, Worship Modes shape how
     5→     5→// mortals pray, Miracles intervene directly, and Heresy rises whenever
     6→     6→// belief fractures. Manage all four and the god ascends to Singularity.
     7→     7→//
     8→     8→// Four mechanic families live in this file:
     9→     9→//
    10→    10→//   1. Divine Laws (8)        — fundamental rule changes, permanent for
    11→    11→//                               the run, cost Divinity. Up to 8 codified
    12→    12→//                               per run (one of each).
    13→    13→//   2. Worship Modes (6)      — pick one at run start; decides how mortals
    14→    14→//                               relate to the god and which bonuses apply.
    15→    15→//   3. Miracles (5)           — dramatic interventions that cost Divinity,
    16→    16→//                               each with a per-run usage limit.
    17→    17→//   4. Heresy Responses (4)   — manage rising heresy (0..100). The run
    18→    18→//                               ends at HERESY_MAX (100); these tools
    19→    19→//                               reduce heresy at various costs.
    20→    20→//
    21→    21→// State fields (planned for GameState — to be wired in a follow-up task):
    22→    22→//   - lawsCodified:        Record<string, boolean>  // laws codified this run (one of each, max 8)
    23→    23→//   - worshipMode:         string | null             // active worship mode id, or null before pick
    24→    24→//   - miracleUses:         Record<string, number>   // times each miracle used this run
    25→    25→//   - miracleTimers:       Record<string, number>   // remaining seconds for active temporary miracles
    26→    26→//   - heresyResponseUses:  Record<string, number>   // times each heresy response used this run
    27→    27→//   - heresy:              number                    // current heresy level (0..100)
    28→    28→//   - heresySchismResolved: boolean                  // whether a schism was resolved this run

    49→    49→ * Base heresy accumulation rate, in points per second, before any laws
    50→    50→ * or worship modes modify it. Effective rate each tick is
    51→    51→ * `BASE_HERESY_RATE * (1 + heresyRateMult(lawsCodified, worshipMode))`.

    80→    80→/**
    81→    81→ * A single Divine Law. Effects are spread across optional fields; the
    82→    82→ * IIFE validator enforces that each law sets at least one. Fields map
    83→    83→ * to consumer wiring as follows:
    84→    84→ *
    85→    85→ *   - `productionMult`        → additive all-production mult (Abundance, Tithe)
    86→    86→ *   - `populationGrowthMult`  → additive pop-growth mult (Fertility)
    87→    87→ *   - `militaryMult`          → additive military mult (Zeal)
    88→    88→ *   - `scienceMult`           → additive science mult (Revelation)
    89→    89→ *   - `goldMult`              → additive gold mult (Tithe)
    90→    90→ *   - `worshipMult`           → multiplicative worship-bonus mult (Faith 2.0)
    91→    91→ *   - `happinessFlat`         → flat per-tick happiness bonus (Mercy +10)
    92→    92→ *   - `happinessTarget`       → clamp happiness to this value while codified (Order 80)
    93→    93→ *   - `heresyDecays`          → UI flag: heresy meter shows "Decaying" (Mercy)
    94→    94→ *   - `heresyFlatOnCodify`    → one-time flat heresy change applied at codification (Faith -20)
    95→    95→ *   - `heresyRateMult`        → additive mult on BASE_HERESY_RATE (Zeal +0.50, Order -0.50, Mercy -2.00)
    96→    96→ *
    97→    97→ * `heresyRateMult` semantics: the effective heresy rate per second is
    98→    98→ * `BASE_HERESY_RATE * (1 + sum_of_law_heresyRateMult + mode.heresyRateMult)`.
    99→    99→ * Mercy's -2.00 makes the factor (1 + -2.00) = -1.0, so heresy decays at

   419→   419→// 4. Heresy Responses (4) — manage rising heresy (0..100; run ends at 100)
   420→   420→// =====================================================================
   421→   421→
   422→   422→/**
   423→   423→ * A single Heresy Response. The player invokes these to keep `state.heresy`
   424→   424→ * below `HERESY_MAX` (100). Each response has a Divinity cost (0 for
   425→   425→ * Tolerate) and a per-run usage limit (`Infinity` for Tolerate, which is
   426→   426→ * always free and unlimited). Effects are spread across optional fields.
   427→   427→ *
   428→   428→ * Effect field → consumer wiring:
   429→   429→ *   - `heresyFlat`      → signed flat heresy change (typically negative)
   430→   430→ *   - `happinessFlat`   → signed flat happiness change (typically negative)
   431→   431→ *   - `populationFlat`  → signed flat population change (typically negative)
   432→   432→ *
   433→   433→ * Note: Tolerate is the "do nothing" option. It costs 0 Divinity, has
   434→   434→ * unlimited uses, and applies no effects. It exists so the player can

   682→   682→/**
   683→   683→ * Aggregated bonus object returned by `divineLawBonus`.
   684→   684→ *
   685→   685→ * All mult fields are additive on top of the baseline (0 = no change);
   686→   686→ * `worshipMult` is multiplicative (1 = no change, 2 = doubled).
   687→   687→ *
   688→   688→ * The consumer applies these in the tick loop:
   689→   689→ *   - `productionMult`:        multiply production by `(1 + productionMult)`
   690→   690→ *   - `populationGrowthMult`:  multiply pop growth by `(1 + populationGrowthMult)`
   691→   691→ *   - `militaryMult`:           multiply military by `(1 + militaryMult)`
   692→   692→ *   - `scienceMult`:             multiply science by `(1 + scienceMult)`
   693→   693→ *   - `goldMult`:                multiply gold by `(1 + goldMult)`
   694→   694→ *   - `worshipMult`:             multiply the worship-bonus by `worshipMult`
   695→   695→ *   - `happinessFlat`:          add to happiness per tick (or per second)
   696→   696→ *   - `happinessTarget`:        if non-null, clamp happiness to this value
   697→   697→ *   - `heresyDecays`:            UI flag; if true the heresy meter shows "Decaying"
   698→   698→ *   - `heresyRateMult`:          passed through to `heresyRateMult` helper
   699→   699→ */
   700→   700→export interface DivineLawBonus {
   701→   701→  /** Additive all-production multiplier (Abundance +0.15, Tithe +0.25). */
   702→   702→  productionMult: number;
   703→   703→  /** Additive population-growth multiplier (Fertility +0.30). */
   704→   704→  populationGrowthMult: number;
   705→   705→  /** Additive military-power multiplier (Zeal +0.40). */
   706→   706→  militaryMult: number;
   707→   707→  /** Additive science multiplier (Revelation +0.35). */
   708→   708→  scienceMult: number;
   709→   709→  /** Additive gold multiplier (Tithe +0.25). */
   710→   710→  goldMult: number;
   711→   711→  /** Multiplicative worship-bonus multiplier (Faith = 2.0; default 1.0). */
   712→   712→  worshipMult: number;
   713→   713→  /** Flat per-tick happiness bonus (Mercy +10). */
   714→   714→  happinessFlat: number;
   715→   715→  /** Happiness clamp target (Order: 80; null = no clamp). */
   716→   716→  happinessTarget: number | null;
   717→   717→  /** Whether heresy decays naturally while codified (Mercy). */
   718→   718→  heresyDecays: boolean;
   719→   719→  /** Additive multiplier on BASE_HERESY_RATE (Zeal +0.50; Order -0.50; Mercy -2.00). */
   720→   720→  heresyRateMult: number;

   722→   722→
   723→   723→/**
   724→   724→ * Sum the bonuses from all codified Divine Laws into a single aggregate.
   725→   725→ *
   726→   726→ * All mult fields are additive (0 = no change) EXCEPT `worshipMult`,
   727→   727→ * which is multiplicative (1 = no change, 2 = doubled by Faith).
   728→   728→ * Compounding multiple laws that set `worshipMult` (currently only
   729→   729→ * Faith) would multiply them; with only Faith in the dataset, the
   730→   730→ * value is 1.0 (no Faith) or 2.0 (Faith codified).
   731→   731→ *
   732→   732→ * Used by the tick loop to compute per-resource multipliers, the
   733→   733→ * pop-growth rate, happiness clamps, and the worship-bonus multiplier.
   734→   734→ * Also feeds the standalone `heresyRateMult` helper for the heresy
   735→   735→ * meter's rate calculation.
   736→   736→ *
   737→   737→ * One-time effects (like Faith's `heresyFlatOnCodify: -20`) are NOT
   738→   738→ * included here — they're applied once by the store at codification
   739→   739→ * time, not per-tick. Read them directly from `DIVINE_LAW_MAP[id]`.
   740→   740→ *
   741→   741→ * @param lawsCodified  Map of law id → codified-this-run flag.
   742→   742→ * @returns Aggregated `DivineLawBonus` (all fields defaulted for empty input).
   743→   743→ *
   744→   744→ * @example
   745→   745→ *   divineLawBonus({})
   746→   746→ *     // → { productionMult:0, ..., worshipMult:1, happinessTarget:null,
   747→   747→ *     //     heresyDecays:false, heresyRateMult:0 }
   748→   748→ *   divineLawBonus({ law_abundance: true })
   749→   749→ *     // → { productionMult:0.15, ..., worshipMult:1, ... }
   750→   750→ *   divineLawBonus({ law_abundance: true, law_tithe: true })
   751→   751→ *     // → { productionMult:0.40, goldMult:0.25, ..., worshipMult:1, ... }
   752→   752→ *   divineLawBonus({ law_faith: true })
   753→   753→ *     // → { ..., worshipMult:2.0, ... }  (multiplicative, not additive)
   754→   754→ *   divineLawBonus({ law_zeal: true, law_order: true })
   755→   755→ *     // → { ..., heresyRateMult:0, ... }  (+0.50 + -0.50 cancel out)
   756→   756→ *   divineLawBonus({ law_mercy: true })
   757→   757→ *     // → { ..., heresyDecays:true, heresyRateMult:-2.00, happinessFlat:10 }
   758→   758→ */
   759→   759→export function divineLawBonus(
   760→   760→  lawsCodified: Record<string, boolean>
   761→   761→): DivineLawBonus {
   762→   762→  const result: DivineLawBonus = {
   763→   763→    productionMult: 0,
   764→   764→    populationGrowthMult: 0,
   765→   765→    militaryMult: 0,
   766→   766→    scienceMult: 0,
   767→   767→    goldMult: 0,
   768→   768→    worshipMult: 1, // multiplicative identity
   769→   769→    happinessFlat: 0,
   770→   770→    happinessTarget: null,
   771→   771→    heresyDecays: false,
   772→   772→    heresyRateMult: 0,
   773→   773→  };
   774→   774→  for (const law of DIVINE_LAWS) {
   775→   775→    if (!lawsCodified[law.id]) continue;
   776→   776→    if (law.productionMult !== undefined) result.productionMult += law.productionMult;
   777→   777→    if (law.populationGrowthMult !== undefined) result.populationGrowthMult += law.populationGrowthMult;
   778→   778→    if (law.militaryMult !== undefined) result.militaryMult += law.militaryMult;
   779→   779→    if (law.scienceMult !== undefined) result.scienceMult += law.scienceMult;
   780→   780→    if (law.goldMult !== undefined) result.goldMult += law.goldMult;
   781→   781→    if (law.worshipMult !== undefined) result.worshipMult *= law.worshipMult;
   782→   782→    if (law.happinessFlat !== undefined) result.happinessFlat += law.happinessFlat;
   783→   783→    if (law.happinessTarget !== undefined) result.happinessTarget = law.happinessTarget;
   784→   784→    if (law.heresyDecays) result.heresyDecays = true;
   785→   785→    if (law.heresyRateMult !== undefined) result.heresyRateMult += law.heresyRateMult;
   786→   786→  }
   787→   787→  return result;
   788→   788→}
   789→   789→
   790→   790→/**
   791→   791→ * Return the active Worship Mode's def, or `null` if no mode is set.
   792→   792→ *
   793→   793→ * Only one worship mode can be active per run (`state.worshipMode` is a
   794→   794→ * single id, not a set). The consumer reads the effect fields directly
   795→   795→ * from the returned def:
   796→   796→ *
   797→   797→ *   const mode = worshipModeBonus(state.worshipMode);
   798→   798→ *   if (mode?.productionMult) production *= (1 + mode.productionMult);
   799→   799→ *   if (mode?.happinessDrainMult) drainRate *= mode.happinessDrainMult;
   800→   800→ *
   801→   801→ * @param modeId  The active worship mode id, or `null` if no mode picked yet.
   802→   802→ * @returns The `WorshipModeDef` for the id, or `null`.
   803→   803→ *
   804→   804→ * @example
   805→   805→ *   worshipModeBonus(null)
   806→   806→ *     // → null
   807→   807→ *   worshipModeBonus("reverence")
   808→   808→ *     // → { id:"reverence", name:"Reverence", ..., productionMult:0.10 }
   809→   809→ *   worshipModeBonus("nonexistent_id")
   810→   810→ *     // → null  (unknown id treated as "no mode")
   811→   811→ */
   812→   812→export function worshipModeBonus(
   813→   813→  modeId: string | null
   814→   814→): WorshipModeDef | null {
   815→   815→  if (!modeId) return null;
   816→   816→  return WORSHIP_MODE_MAP[modeId] ?? null;
   817→   817→}
   818→   818→
   819→   819→/**
   820→   820→ * Compute the additive multiplier on `BASE_HERESY_RATE` from codified
   821→   821→ * Divine Laws and the active Worship Mode.
   822→   822→ *
   823→   823→ * Sources (all additive):
   824→   824→ *   - Law of Order:    -0.50  (slower heresy: rate × 0.5)
   825→   825→ *   - Law of Zeal:     +0.50  (faster heresy: rate × 1.5)
   826→   826→ *   - Law of Mercy:    -2.00  (heresy decays: rate × -1.0)
   827→   827→ *   - Mystery mode:    -0.25  (slower heresy: rate × 0.75)
   828→   828→ *
   829→   829→ * The effective per-second heresy rate is:
   830→   830→ *   `BASE_HERESY_RATE * (1 + heresyRateMult(lawsCodified, worshipMode))`
   831→   831→ *
   832→   832→ * With no laws / mode: 0 → rate = +0.05/s.
   833→   833→ * With Zeal + Fear:    +0.50 → rate = +0.075/s.
   834→   834→ * With Mercy alone:    -2.00 → rate = -0.05/s (heresy decays).
   835→   835→ * With Order + Mystery: -0.75 → rate = +0.0125/s.
   836→   836→ *
   837→   837→ * @param lawsCodified  Map of law id → codified-this-run flag.
   838→   838→ * @param modeId        Active worship mode id, or `null`.
   839→   839→ * @returns Additive multiplier on `BASE_HERESY_RATE` (0 = no change).
   840→   840→ *
   841→   841→ * @example
   842→   842→ *   heresyRateMult({}, null)
   843→   843→ *     // → 0
   844→   844→ *   heresyRateMult({ law_zeal: true }, null)
   845→   845→ *     // → 0.50
   846→   846→ *   heresyRateMult({ law_mercy: true }, null)
   847→   847→ *     // → -2.00  (heresy decays at base rate)
   848→   848→ *   heresyRateMult({ law_order: true }, "mystery")

   853→   853→export function heresyRateMult(
   854→   854→  lawsCodified: Record<string, boolean>,
   855→   855→  modeId: string | null
   856→   856→): number {
   857→   857→  let mult = 0;
   858→   858→  // From codified laws.
   859→   859→  mult += divineLawBonus(lawsCodified).heresyRateMult;
   860→   860→  // From active worship mode.
   861→   861→  const mode = worshipModeBonus(modeId);
   862→   862→  if (mode?.heresyRateMult !== undefined) {
   863→   863→    mult += mode.heresyRateMult;
   864→   864→  }
   865→   865→  return mult;
   866→   866→}
