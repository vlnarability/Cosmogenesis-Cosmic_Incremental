F2+F3+F4+F5 + S1+S5: cosmetics, autobuyer presets, shortcuts overlay, sparklines, accent strip, tab transitions

F2 — Autobuyer presets:
- New state field: autoBuyerPresets (Record<string, AutoBuyerSettings>).
  Persists across prestiges (meta state).
- New actions: saveAutoBuyerPreset(name), loadAutoBuyerPreset(name),
  deleteAutoBuyerPreset(name).
- New AutobuyerPresetsSection component in ShopModal — compact
  save/load/delete UI at the bottom of the AutobuyerSettingsPanel.
  Name input (max 30 chars) + Save button. Preset list shows name +
  config summary (systemTarget/techTarget/government abbreviated).
  Load (Upload icon) + Delete (Trash2 icon, confirm dialog) buttons.
  Empty state: "No presets saved yet."

F3 — Cosmetics system (wired the cron-created stubs):
- New state: showCosmetics (transient), aetherShards, ownedCosmetics,
  activeCosmetics (all persist across prestiges).
- New actions: setShowCosmetics, purchaseCosmetic (spends shards,
  auto-equips), equipCosmetic, grantAetherShards.
- Aether Shards granted on stage clear (1 per stage cleared, capped at
  99999 lifetime). Persists through prestige.
- CosmeticsModal rendered in GameShell (lazy-loaded).
- "Cosmetics" menu item in gear dropdown with Aether Shard count badge.
- Active cosmetic theme class applied to root wrapper (alongside stage
  theme). 5 theme CSS classes: theme-emerald, theme-ember, theme-rose,
  theme-void, theme-astral (override CSS variables).
- Icon overrides applied to ResourceBar chips via getActiveIconOverrides.

F4 — Keyboard shortcuts overlay:
- New state: showShortcuts (transient) + setShowShortcuts/toggleShortcuts.
- "?" key handler in useKeyboardShortcuts opens the overlay (works even
  when modals are open). Escape closes it.
- New ShortcutsOverlay component — lightweight Dialog showing current
  bindings grouped by category (Universal / Prestige Layers). Read-only
  (rebinding is in Settings → Shortcuts). Layer-gated actions only show
  when their layer is unlocked.
- "Shortcuts" menu item in gear dropdown with "?" kbd badge.

F5 — Resource production sparkline:
- New state: resourceRateHistory (Record<string, number[]>, transient) +
  _rateSampleTimer (transient accumulator).
- Tick samples net rates every ~1s via computeResourceBreakdown, pushes
  to history (capped at 60 entries per resource).
- New SparklinePath component in ResourceBar — mini SVG sparkline (60×8
  viewBox) rendered in each resource chip. Color matches net direction
  (emerald=positive, red=negative, muted=idle). Non-scaling stroke.
- Only renders when ≥2 samples exist (avoids single-point artifacts).

S1 — StagePanel accent strip:
- Thin vertical bar (w-1) on the left edge of the StagePanel using the
  stage's accent color (gradient from full color to 25% opacity).
  Gives each stage a distinct visual identity without being loud.
