C1 + F11: 3D visualizer polish + per-stage stats breakdown

C1 - Divine Engine 3D visualizer polish (WorldVisualization3D):
- Replaced indigo/blue dominant tier palette with a cosmic one:
  silver -> green -> cyan -> gold -> amber -> magenta ->
  crimson -> emerald -> violet -> gold-core, with luminous
  white-gold for Ascendant+ and obsidian for Void.
- Auto-rotate speed is now adjustable (0-24 deg/s slider, default 8).
  Pause/play button toggles rotation without needing to drag first.
- Tier filter chips in the legend - click a tier to hide/show its
  instances. Hidden tiers scale to 0 (no InstancedMesh realloc).
  "Show all" button restores hidden tiers.
- Reactive legend via useGameStore subscription (was getState()
  inline, not reactive). Each chip shows tier count.
- World count overlay (top-right): "N / M worlds" visible vs total.
- Glow halos for higher tiers (Tier 5+): second InstancedMesh with
  additive-blended sphere geometry scaled 1.4x gives Ascendant /
  Celestial Core worlds a luminous corona.
- Subtle radial FogExp2 so distant worlds fade into the void.
- Sphere geometry bumped 16/12 -> 24/18 segments for smoother
  highlights. Material emissive 0x101030 @ 0.4 intensity for
  self-luminous look.
- Starfield count 200 -> 300, rotates slower than worlds (parallax).
- Pixel ratio capped at 2 for perf on high-DPI displays.
- reduceMotion: when on, auto-rotate defaults to 0 and the
  rotation slider is hidden.
- DivineEngineFullTab now re-exports TIER_COLORS + WorldDot from
  WorldVisualization3D (single source of truth).

F11 - Stats dashboard per-stage breakdown:
- New GameState fields (persist version 27 -> 28, migration added):
    stageTimeTotals: Record<StageId, number>      (lifetime sec/stage)
    stageSystemsBuilt: Record<StageId, number>    (lifetime builds/stage)
    stageTechsResearched: Record<StageId, number> (lifetime techs/stage)
    stageRunTimes: Record<StageId, number>        (current-run sec/stage,
                                                   resets on prestige)
- Tick accumulates realDt into both stageTimeTotals[curStage] and
  stageRunTimes[curStage] each frame.
- buySystem increments stageSystemsBuilt[curStage] by `bought`.
- buyTech increments stageTechsResearched[curStage] by 1.
- Prestige path resets stageRunTimes to all-zeros (new run) while
  keeping the three lifetime counters intact.
- StatsTab gains a "Per-Stage Breakdown" card with:
    - One row per stage (Cell -> Galactic), color-coded by status
      (current = primary, past = emerald, future = muted).
    - Lifetime time bar (share of total playtime).
    - This-run time, lifetime systems built (count), systems owned
      /max types (with mini progress bar), techs researched (count),
      techs owned/max types (with mini progress bar).
    - Summary footer row with totals (lifetime time, run time,
      systems, techs).
    - Mobile-responsive: 2-col on mobile, 4-col on >=sm.
- Migration defaults all four records to zero-keyed maps for old saves.
