C2 + F12: constellation map polish + hardmode leaderboard

C2 - Constellations map polish (EnlightenmentModal + constellations.ts):
- Hemisphere split:
  - Equator line at y=50% (dashed cyan, full sky width).
  - Large N/S hemisphere labels at the left edge of each sky instance.
  - Subtle top-half cyan tint (northern sky) + bottom-half purple tint
    (southern sky) at opacity ~0.06.
- Cluster grouping:
  - Precomputed CLUSTER_BOUNDS in constellations.ts — one bounding box
    per category (zodiac/northern/equatorial/southern) covering all of
    that category's constellations.
  - Dashed rounded rect per cluster (SVG layer, separate from the
    constellation connection lines).
  - Category label at the top-center of each cluster (uppercase
    monospace, accent-colored).
- Constellation SVG pattern upgrade — three distinct line styles:
  - Completed: solid accent line + SVG glow filter (feGaussianBlur +
    feMerge) + endpoint dots (r=0.35).
  - Started: dashed accent line (stroke-dasharray="1.2 0.8") +
    smaller endpoint dots.
  - Revealed: sparser dashed line at lower opacity.
  - Unstarted/dim: very faint slate line.
  - Glow filter is per-sky-instance (so filter regions don't bleed
    across the infinite-scroll copies).
- Completion ring (top-right of sky viewport):
  - Circular SVG arc showing % of CONSTELLATIONS_REQUIRED_FOR_LAYER_3
    completed. 36x36 viewBox, r=16, stroke-dasharray animation.
  - Center percentage text + "N/20 to L3" subtitle.
  - Turns emerald at 100%.
- Per-hemisphere completion bars (below-sky summary):
  - Three mini progress bars (north/ecliptic/south) showing completed
    vs total constellations per hemisphere.
  - Accent colors match the hemisphere tint (cyan=north, amber=ecliptic,
    purple=south).

F12 - Hardmode leaderboard (localStorage-based fastest-clear records):
- New src/game/data/hardmodeLeaderboard.ts:
  - HardmodeClearRecord interface: stageId, clearTimeSec, realTimeSec,
    runTimestamp, runNumber, nucleusChoice, ascensionPath, government,
    totalSystemsBuilt, totalTechsResearched.
  - loadLeaderboard / saveLeaderboard / addHardmodeClearRecord /
    getTopClearsForStage / getFastestClearForStage / getRankForClear /
    clearLeaderboard / totalRecordCount.
  - Per-slot storage (key cosmo_hardmode_lb_v1_slot{N}), wired via
    configureLeaderboardSlotLookup(getCurrentSlot) at store init.
  - Schema version field for future migrations.
  - MAX_RECORDS_PER_STAGE = 50 (sorted ascending by clearTimeSec).
- Store wiring (evolve action):
  - When difficultyMode === "hard", captures stageRunTimes[stageId]
    as the clear time + writes a record via addHardmodeClearRecord.
  - Wrapped in try/catch — leaderboard failures never break the
    evolve flow.
- Types: activeInfoModal + openInfoModal extended to include
  "leaderboard".
- New LeaderboardTab component:
  - Header card: hardmode badge, total records, per-stage summary grid
    (7 stages, click to select), online-sync placeholder, refresh +
    clear buttons.
  - Records table: rank (#), build (nucleus/ascension/government),
    time, systems, techs, run number. Crown icon for the top record.
  - Empty state: "No hardmode clears recorded for this stage yet."
  - Mobile-responsive: 3-col on mobile, 6-col on >=sm.
- GameShell InfoModal: renders <LeaderboardTab /> when
  activeInfoModal === "leaderboard". META entry with Timer icon.
- Header gear dropdown: new "Leaderboard" item between Statistics
  and Settings.
